# C++ OpenCV 图像形态学操作

## 概述

图像形态学操作：基于数学形态学的图像处理技术，专注于分析和处理图像的形状和结构。针对二值图像和灰度图。

主要解决：

1. 去除噪声
2. 分离连接的物体
3. 填充孔洞
4. 提取边界
5. 增强特定形状

## 结构元素

element 为结构元素。

`Mat element = getStructuringElement(shape, size)`

- 矩形 `MORPH_RECT`：通用。
- 椭圆 `MORPH_ELLIPSE`：圆形物体。

建议放入灰度图效果更好。形态学操作的输出类型和输入类型一致，输入二值图，输出二值图；输入灰度图，输出灰度图。

## 通用函数

`morphologyEx(inputImg, outputImg, op, Kernel, anchor, iteration, borderType = BORDER_CONSTANT, borderValue -> 黑)`

- op 为操作类型，例如腐蚀、膨胀、开运算等。
- iterations 表示迭代次数：操作类型反复执行的次数。

## 腐蚀

将结构元素在图像上"移动"，对于每个像素点，只有当结构元素完全包含在前景中，该像素才被保留 -> 前景图像区域变小 -> 最小值替换中心像素。

- 作用：去除小噪声（如白色噪点），分离连接的物体。
- `erode(inputImg, outputImg, element)`

## 膨胀

将结构元素在图像上"移动"，对于每个像素点，只要该元素与前景有交集，该像素就会被保留 -> 前景图像区域变大 -> 最大值替换中心像素。

- 作用：填充小孔，连接断开的物体。
- `dilate(inputImg, outputImg, element)`

## 开操作与闭操作

> 开运去白点，闭运填黑洞。
> 开开分粘连，闭闭连断裂。

- 开操作：腐蚀 -> 膨胀。去除小白点，分离粘连物体。
- 闭操作：膨胀 -> 腐蚀。填充小黑点，连接断裂物体。

## 形态学梯度

- 边缘图：通过边缘检测算法（包括形态学梯度）得到的二值图像。
- 形态学梯度（基础梯度）：通过膨胀 - 腐蚀差值得到的图像（可能是灰度图或二值图），展现的是整体轮廓。
  - 公式：形态学梯度 = 膨胀图像 - 腐蚀图像。
  - 相较于 Canny 边缘提取，形态学梯度提取边缘的优缺点：
    1. Canny 边缘检测适用于高精度边缘的场景，形态学梯度适用于提取物体轮廓的场景。
    2. Canny 抗噪性更强，而形态学更适合轮廓提取。
  - 通过 `MORPH_GRADIENT` 放入 `morphologyEx()` 中实现。
- 内梯度：方块内部边界。内部梯度 = 原图像 - 腐蚀图像。
- 外梯度：方块外部边界。外部梯度 = 膨胀图像 - 原图像。

## 顶帽

- 顶帽 = 原图像 - 开运算的图像。
- 突出显示比周围亮的小区域（kernel 应与目标图像大小和形状相似）。

## 黑帽

- 黑帽 = 闭运算的图像 - 原图像。
- 突出显示比周围暗的小区域（kernel 应与目标图像大小和形状相似）。

## 击中不击中

一种用于精准检测特定形状的二值图像操作。只有当匹配前景击中、匹配背景不击中时，该点才被保留 -> 只检测目标形状，不检测出其他形状。

设置两个结构元素：

- B1 匹配目标形状的前景部分：
  ```cpp
  cv::Mat B1 = (cv::Mat_<uchar>(3,3) << 0,1,0,1,1,1,0,1,0);
  ```
- B2 匹配目标形状的背景部分：
  ```cpp
  cv::Mat B2 = (cv::Mat_<uchar>(3,3) << 1,0,1,0,0,0,1,0,1);
  ```

操作步骤：

1. 二值图与 B1 进行与操作。
2. 背景图（二值图取反）与 B2 进行与操作。
3. 两者再进行与操作。
