# 经典机器学习

> 传统机器学习算法。逻辑回归 = 线性组合 → sigmoid，是单神经元网络的雏形，深度学习篇讲神经元时会链接到这里。
> 相关笔记：[[机器学习指引]] · [[深度学习]] · [[量化与部署]]

## 1. 机器学习和深度学习能处理问题的特征

### 传统机器学习：特征工程是关键
- 处理规律明显、数据结构化、对计算资源敏感的问题
- **数据结构化**：原始数据很容易整理成 Excel 表格
- **特征可描述性**：能用数学或逻辑清晰定义出特征（如找直径 > 10cm 的圆）
- **小样本量**：只需几百个或几十个样本
- **强可解释性**：决策过程透明
- **低算力**

### 深度学习：特征学习是核心
- 处理维度极高、人类难以描述、数据量巨大的问题
- **数据非结构化**：原始数据是像素点、波形图或长文本
- **特征极其复杂**：人类难以用数学公式定义特征
- **海量数据驱动**：通常需成千上万个样本才能达到较高准确率
- **黑盒属性**：模型虽准但难解释参数如何协作
- **高算力**

## 2. 机器学习的主要类型

- **无监督学习**：识别未标记数据中的模式或结构（如聚类）
- **监督式学习**：用已标记数据训练模型，学习映射函数预测新数据。分类（选择题）+ 回归（填空题）
- **强化学习**：智能体在环境中执行动作学习决策，最大化累计奖励

## 3. 机器学习中的 Fw,b(x)

- **x（特征向量）**：代表「现实世界的数据」，装的是收集到的各项物理量或特征（如 x = [距离，抓取次数，重量...]）
- **w（权重向量）**：代表「每个数据有多重要」。w 不替换多维事物，而是模型学出的规律；w 中每个数字严格对应 x 里的每个特征，代表该特征对最终结果的「影响力」

## 4. 线性回归

- **代价函数**（又称平方误差函数）：衡量模型预测值与 y 实际真实值之间的差异

### 梯度下降（基础）
梯度下降是求函数最小值的算法。因为没尝试完所有参数组合，不能确定得到的局部最小值是否全局最小；选不同初始参数可能找到不同局部最小值。

### 学习率（基础）
学习率决定沿代价函数下降最大的方向迈出步子的大小。
- 学习率过小：达到收敛所需迭代次数非常高
- 学习率过大：每次迭代可能不减小代价函数，可能越过局部最小值导致无法收敛

> 深度学习中更细的梯度/学习率/Adam/归一化输入/梯度消失爆炸见 [[深度学习]]。

### 向量化
将数据向量化能提高计算速度，即转成 numpy 形式。
- 点积（数量积/内积）：两个向量相乘得到标量
- `np.dot(w, x)` 对两个向量做点积计算

### 特征缩放
尝试将所有特征尺度都尽量缩放到 -1 到 1 之间。

## 5. 分类

- **损失函数**：对单个样本的作用，针对某个数据预测值与真实值的差异
- **代价/成本函数**：作用于整个训练集，是所有样本损失的平均值

## 6. 逻辑回归

逻辑回归：将线性组合的结果映射到一个概率值上（使用 Sigmoid 函数）。
- 概率定义要求输出严格落在 [0,1]；Sigmoid 能把 -∞ 到 +∞ 的任意实数「压缩」「平滑映射」到 0~1
- **决策边界**：模型在特征空间中划出的一条「界限」，物理性分割不同类别
- **特征选择**：选择最合适的特征集

> 逻辑回归在数学上等价于「激活函数为 sigmoid 的单个神经元」，是神经网络的雏形。详见 [[深度学习]] 的神经元一节。

### 欠拟合
模型在训练数据上表现很差，在新数据上表现也很差，没捕捉到基本规律。
- 原因：模型简单、特征数少、训练次数少

### 过拟合
模型在训练数据上近乎完美，但新数据上一塌糊涂（把训练集的「噪声」和「随机波动」当成了普遍规律）。
- 原因：模型太复杂、数据量太少、特征数过多、训练过度
- 解决方法：① 增加数据量 ② 减少特征数 ③ 使用正则化减少参数大小

> 正则化的详细讲解（L1/L2、Dropout、数据增强、早停）见 [[深度学习]]。

### 合适拟合（理想状态）
追求泛化能力，通过数据集总结通用规律，无论遇到什么新数据都能从容应对。

## 7. 精准率与召回率

处理类别不平衡或稀有类别时，帮助判断学习算法是否做出良好预测：
- 精准率 = 真阳性数 / 预测阳性数
- 召回率 = 真阳性数 / 实际阳性数
- 宁可错杀一千，不可放过一个 → 优先保召回率 → 摔倒检测
- 宁可放过一千，不可错杀一个 → 优先保精确率 → 药品分发

提高精准率/召回率：
- 提高判断阈值 → 提高精准率，降低召回率
- 降低判断阈值 → 降低精准率，提高召回率

权衡精准率与召回率：
1. 绘制阈值变化对精准率和召回率的影响曲线
2. 在曲线上选一点，平衡假阳/假阴成本，或平衡高精准率与高召回率

## 9. 学习曲线

绘制学习曲线（随训练集增加，Jtrain 和 Jcv 的关系）：
- 训练集越大 → Jtrain 变大 → Jtrain 和 Jcv 越接近，Jcv 变小

- 高方差：最终 Jtrain 和 Jcv 与基准性能水平相近

## 10. 决策树

决策树包含根节点、内部节点、叶子节点，本质是由算法自动从数据中学习生成的、嵌套的 if-else 规则集合（算法自动找出最优特征和阈值做条件判断，本质是不等式范围判断，如 x <= t）。
- 任务：从所有可能决策树中挑一个在训练集表现良好、且能泛化到新数据的树

### 纯度
纯度衡量一个节点中样本分类一致性。节点所有样本同类 → 纯度极高；均匀混合各类 → 纯度很低。
- **熵函数**：衡量数据集纯度的指标。熵越小样本越纯，熵越大越不纯；全是一类或全非一类样本熵为 0

### 节点的深度
从根节点到达该节点的跳数。限制深度是为了确保树不会太大难以管理，也因树小不容易过拟合。

### 构建决策树的选择
1. 选哪个特征分类：找能导致左右分支标签纯度最高的特征
2. 何时停止分裂：如纯度分数改进低于某个阈值

### 信息增量
衡量通过分割获得的熵的减少量：信息增量 = 根节点熵 - 分割后熵。
- 若熵的减少量太小（小于阈值），就没必要冒着增加树大小、过拟合的风险分割

### 构建大型决策树的步骤
1. 从根节点开始含所有样本，计算所有特征的信息增量，选最高的进行分裂
2. 按所选特征分成两个子集，创建左右分支，按特征值发送样本
3. 在左右分支重复分裂直到满足停止标准
   - 停止标准：① 节点 100% 单一类别（熵为 0）② 超过最大深度 ③ 信息增益小于阈值 ④ 节点样本数小于阈值

### 独热编码与多热编码
- 分类特征取 K 个可能值，只取其中一个 → 用 K 个二元特征替换（独热编码）
- 分类特征能取两个或更多、且类别独立可共存 → 多热编码

### 连续值特征
考虑分割时只需考虑不同分隔值，计算信息增益，若该连续特征能提供最高信息增量则在该特征上分割。

### 决策树解决回归问题
思路类似分类，只需将信息增量改为**方差减少量**（停止标准相应改为方差为 0、超过最大深度、方差减少量小于阈值、样本数小于阈值）。

### 树集成
单一决策树对数据集更改的结果差异巨大、鲁棒性差。用多个决策树投票，使整体算法对任何单一树的行为不那么敏感。

#### 随机森林
一种非常强大的树集成算法，效果远优于单一决策树。
- 有放回抽样：构建新训练集，与原数据集类似又不同
- 过程：从原数据集有放回抽样 m 次，训练决策树，反复 M 次（M 在 64~128 之间，让所有树投票）。M 更大永不损害性能，但超过 128 后性能不显著提高、只减缓计算
- 算法修正：每个节点随机化特征选择，使树集成更不同，投票更准（有 n 个特征选 k 个作为允许特征，从中选信息增益最高的分裂）

#### XGBoost
类似随机森林，但为不同训练样本分配不同权重（对之前决策树分类错误的样本权重更高），不需要生成大量随机选择的训练集。

## 11. SVM（支持向量机）

- **超平面**：不同种类之间的分界线
- **支持向量**：离分界线最近的那几个点，整个 SVM 的生死全靠这些点决定，其他离得远的点怎么移动都对这条线毫无影响
- **间隔**：两个类别支持向量的距离。SVM 的目标是把间隔弄得越大越好

### 软间隔与惩罚系数 C（允许犯错的尺度）
数据 A 中混进一个数据 B 的样本点时，要么妥协（间隔变小但分类全对），要么忽视（维持间隔、容忍错误）：
- C 很大：牺牲间隔距离（容易过拟合）
- C 很小：追求间隔距离、允许少量错误（泛化能力好）

### 核技巧
数据 A 在内圈、B 在外圈时，核函数把 A「拍到」空中变成 3D，切一刀就能完美分割。
- **linear（线性核）**：数据本就能用直线分开。速度快、不易过拟合；数据分布稍弯曲就瞎。适用特征特别多但样本一般、数据量大追求速度
- **rbf（高斯核）**：最常用，能应对绝大多数复杂弯曲边界，可画任意闭合曲线、圆圈、孤岛。非常灵活但计算量大，调参不好易过拟合。适用特征少、样本量中等且关系复杂。需调 C 和 Gamma（控制单个样本影响范围）
- **poly（多项式核）**

### 数据预处理
训练前要全局标准化（SVM 计算几何距离）：
- 不标准化，一个极端数据会把 SVM 分界线冲得稀烂；标准化降低极端数据对其他特征的打击
- Xnew = (Xold - Mean) / std

## 12. 随机森林 VS 支持向量机（SVM）

### SVM
目标是在数据中划出完美「三八线」，让不同类别数据离这条线尽可能远。
- 数据特点：适合高维数（特征列数多）、低样本、纯数值
  - 关键点坐标必须归一化
  - 对小样本泛化能力强
  - 适合复杂几何边界：非线性关系时可用高斯核映射到高维
- 缺点：对噪声敏感

### 随机森林
由几百棵决策树组成，结果投票决定。
- 数据特点：适合特征杂乱、类型多样、有噪点
  - 可传混合型数据（传感器数值、状态标志位），可有缺失值
  - 不需繁琐预处理（如全局标准化）
  - 自带特征解释：`setCalculateVarImportance(True)` 可在 Python 侧打印哪些特征贡献最大
  - 鲁棒性强，能轻松滤掉噪声
- 缺点：模型文件大、占内存

### 强行二选一的解决
1. **硬分类改软分类**：调用概率，最高概率低于阈值则输出未知/无法识别
2. **前置异常检测**：
   - **孤立森林**：异常数据往往「稀少」且「离群」，最容易被孤立。样本在树里深度很浅即判定异常得分高
     ```python
     IsolationForest(contamination=0.05, n_estimators=100, max_samples="auto")
     # contamination：训练集噪点占比，拦截更严可调 0.1/0.15，不想误杀正常数据可调小
     # n_estimators：孤立树棵数，默认 100 即可
     ```
   - **单类 SVM**：只给模型看正常数据，在正常数据周围画封闭轮廓，落在轮廓外就是异常。不关心类别间分界线。Gamma 越大是「紧身衣」；NU 越大对边缘噪点排斥率增加

## 13. 使用 SVM 训练模型

- 静止姿态分类：提取特征，再对特征打标签
- 动态姿态分类：
  1. **暴力拼接法**：将连续动作视频的特征点提取拼成非常长的数据条
  2. **特征工程法**（SVM 非常喜欢提炼过的数据，训练快且不易出错）：将 30 帧数据提炼成关键物理量
- 用于训练的数据维数必须相等
- 必须将坐标归一化：绝对坐标对拍摄距离和人在画面中的位置极其敏感，人离镜头远近会导致 SVM 识别错误

## 14. 决策树 VS 神经网络

- **决策树**：在表格数据上表现良好（数据集像巨大电子表格，含分类/连续特征，适用分类或回归）。训练速度极快，分类过程可视化。
- **神经网络**：在结构化数据和非结构化数据上都表现良好，非结构化数据（图像/视频/音频/文本）首选。训练速度缓慢。可用迁移学习（少量数据时在大数据集预训练）。多模型协同系统串联训练比多个决策树更容易实现。

## 15. 无监督学习

聚类算法查看一组数据点，自动找出相互关联或相似的数据点。

### K-Means 聚类算法
**步骤**：
1. 随机猜测两个聚类中心位置
2. 移动这些点到更近的聚类（按距离判断）
3. 将每个聚类中的点取平均值，平移聚类中心
4. 遍历每个点判断属于哪类聚类
5. 分配到更近的聚类
6. 反复直到聚类点和中心位置都不再变化

- **失真代价函数 J**：所有数据点到各自簇中心距离平方和的平均数。若用簇中心 μ 替代簇内数据点 x，数据点离中心远则代替丢失大量原始信息（失真严重）
- **优化 J**：先分配数据点，再更新聚类中心位置；每次迭代 J 应下降或保持不变
- **测试收敛**：迭代后 J 是否下降，一旦保持不变通常意味着 K-Means 收敛
- **多次随机初始化**：选 k 个训练样本初始化中心，运行到收敛，计算 J；重复 50~1000 次，选 J 最低的那组。每次得到的都是局部最优，需多次才能找到全局最优
- **聚类数量选择**：① K 增加 J 一定减少，选下降趋势突然变缓的拐点；② 按实际场景判断（如三种型号衬衫分三类）

## 16. 异常检测算法

查看一个未标记的正常（或混有极少未知异常）事件数据集，检测出不合格的异类。前提：学习的数据必须是高斯分布，否则需变换使其变为高斯分布。

### 核心作用
- 从未知威胁中抽身：不需要知道异常长什么样，只要跟其他数据不一样就能揪出来
- 极度不平衡数据的解药：异常只占极少部分时传统分类模型罢工，异常检测正合适

### 底层逻辑
学习一批正常数据的分布规律，计算概率模型 p(x)。新数据输入时计算它属于「正常分布」的概率：概率大 → 正常；概率小 → 几乎不可能出现，就是异常。

### 高斯分布曲线
- σ 越大曲线越矮；μ 变化导致曲线左右平移
- 特征相对训练集非常大或非常小，往往标记为异常

### 判断规则
- p(x) < ε → 判定为异常
- p(x) > ε → 判定为正常
- 用交叉验证集挑选合理 epsilon

### 挑选正确的特征
监督学习即使特征不正确，也会设置权重自动忽视或重新缩放不正确的特征；异常检测仅从无标签数据学习，更难自行决定忽视哪些特征。开发：训练模型 → 看算法在交叉验证集中未检测到的异常 → 启发创建新特征，使算法识别该样本在新特征上取值异常大或小。

### 异常检测 vs 监督学习
- **看待方式**：监督学习像非黑即白的法官，需提供清晰正反例，极度依赖标签完备性；异常检测只看正常数据并划边界，落在圈外即异常
- **选择**：异常数据明确、已知 → 监督学习；异常数据隐蔽、未知、种类多 → 异常检测

## 17. 推荐系统

推荐系统本质是信息过载系统，训练出的模型预测「用户对物品的偏好程度」。
- **基于内容的推荐**：依赖物体本身特征和用户历史画像
- **协同过滤**：将特征向量 x 自己学过来，本质是矩阵分解和特征降维
  - 过程：① 定义 xi 为第 i 个物品隐藏特征向量、Θj 为第 j 个用户偏好参数向量 ② 所有 x 和 Θ 赋极小随机数 ③ 用当前 x、Θ 算预测值，对比真实评分矩阵 Y 得误差 ④ 对代价函数求偏导，每次迭代对 Θ 和 x 梯度下降 ⑤ 算出准确的 x 和 Θ

## 18. 强化学习（简化）

强化学习是机器学习的一个分支，在试错中成长。
- **核心思想**：与环境交互，做对得奖励、做错受惩罚，学会一套「在什么状态做什么动作」的策略
- **步骤**：智能体观察状态 Si，做动作 Ai，环境给奖励 Ri+1 并转入状态 Si+1。目标最大化长期累计奖励总和
- 需要设计好奖励函数 Reward

### 基本概念
- **回报**：系统获得奖励的总和，按折扣因子加权，未来奖励按折扣因子更高次方加权
- **折扣因子 γ**：取值 [0,1)，平衡眼前与长远利益，γ 越接近 1 越看重长远回报
- **策略 Π**：接收状态 S 映射到要采取的动作 a：Π(S) = a
- **MDP（马尔可夫决策）**：未来只取决于当前状态
- **Q 函数**：评估状态 s 下执行动作 a 的「长远回报」：Q(s,a)
- **V 函数**：评估状态 s 本身好不好（不关心具体动作）
- **贝尔曼方程**：将 Q(s,a) 拆成「当前即时奖励」+「下一步 Q 值」

### 随机性与期望
环境有随机性，未来回报无法确定，不能靠单一结果判断。应调整策略，让所有可能结果在概率加权平均（期望）后折扣总奖励最大。

### 奖励函数设计
构建强化学习应用时需思考想要和不想要什么并编码进奖励函数。指定奖励函数比指定每个状态的正确动作容易，但对许多应用仍很困难。

### DQN
训练一个神经网络计算/近似状态动作价值函数 Q(S,A) 来选择好动作。
**算法**：① 随机初始化神经网络参数 ② 建回放缓冲区（随机飞行收集 (状态, 动作, 奖励) 元组）③ 用元组训练模型 Qnew(s,a) ≈ y ④ 用贝尔曼函数收敛 Q，用 epsilon-贪心（0.95 概率选收益最大行动，0.05 随机选，epsilon=0.05）

## 19. sklearn 与 YOLO 入口

### Scikit-learn（sklearn）
- **算法库**：集成所有经典传统机器学习算法（SVM、随机森林、逻辑回归、K-Means 等）
- **工业级工具箱**：具备完整数据处理流水线（Pipeline），把复杂任务流程化

### YOLO 模型
- Python 中一般直接调用 `.pt` 格式；其他环境（C++、C#、Java、树莓派）一般只用 `.onnx` 格式
- 目标检测关注点：找位置 + 是什么
- 训练与导出代码：
  ```python
  model = YOLO(模型地址)          # 导入模型
  yaml_path = yaml地址            # 传入 yaml 地址
  results = model.train(data=yaml_path, epochs=50, imgsz=640, batch=8)
  # epochs=50 -> 数据集反复学习 50 次
  # imgsz=640 -> 图片缩放至 640*640
  # batch=8  -> 每次使用 8 张显卡
  model.export(format="onnx")     # 导出为 onnx 格式
  ```

## 20.差分学习率

- 在迁移学习或模型微调中，为神经网络的不同层设置不同的学习率的训练策略
	- 浅层网络：提取的是通用物理特征，这些特征不需要大幅改动
	- 中深层网络：提取局部部件或几何组合，需要根据新任务做小幅度微调
	- 顶层/分类头：是为了新任务全新初始化的随机权重，需要快速更新并建立映射
