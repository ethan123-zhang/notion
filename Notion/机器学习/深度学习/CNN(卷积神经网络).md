# CNN(卷积神经网络)

## 卷积

- 卷积是拿一个小矩阵在另一个大矩阵上按规律滑动、加权相乘并求和的动态计算
- 卷积运算是卷积神经网络的基本组成单元

- 同一个卷积层的宽和高一般是等长的。（一般在高宽比极端的图像中采取非等长卷积核）

### 卷积核大小通常为奇数的原因

- 保证Same卷积的对称性 -> 保证原特征图的填充层数p为整除
- 拥有天然的“中心像素“ 
	- 奇数核拥有唯一的中心点，在计算机视觉中方便把当前卷积计算的结果精确绑定并映射到中心像素的几何坐标上
	- 卷积核通常呈现中心权重最大/最关键，周围权重呈放射或对称衰减

## 边缘探测

- 卷积不仅能感知边缘的存在，还能分辨边缘的渐变方向。
     若只关心边缘位置，而不关心方向，可通过绝对值操作将其统一

- 通过反向传播与梯度下降，神经网络会自动学习出最适合当前任务的特征提取器 -- 不仅能学会水平和垂直边缘检测，还能自动发现任意角度的边缘，甚至更复杂的纹理和高维模式

## Padding(填充)

### 为什么采取
- 为了放置图像尺寸不断减小 -> 如果没有Padding,深层网络的特征图会迅速缩减为1 * 1，导致无法构建深层神经网络
- 边缘/角落信息严重丢失 -> 导致原图边界处的信息被稀释甚至直接丢弃
	- 角落像素指挥参与一次计算
	- 中心像素会被多次计算

### 解决方式

**常见的卷积选择**

1. Valid -> 无填充 -> 图像每次卷积都会按核大小逐渐缩小
2. Same -> 同尺寸卷积 -> 通过往原图像外围绕$p = \frac{f - 1}{2}$圈0(f为卷积核的边长，且[[CNN(卷积神经网络)#卷积核大小通常为奇数的原因|卷积核大小通常为奇数]])，使卷积输出尺寸与输入尺寸保持严格一致，并且保证了每个像素点都当过中心像素点（确保了真实内容为主体，不会像Full填充一样真实信息被稀释）
3. Full卷积 -> 保证原图像中每个像素点计算次数都相同 -> 源图像往外围绕p = f - 1圈0
	   [[转接文件库#不采用Full填充的原因|不采用Full填充的原因]]

## Stride(卷积步长)

- 卷积核在输入图像上每次滑动的像素间隔跨度
$$\text{输出尺寸} = \left\lfloor \frac{n + 2p - f}{s} + 1 \right\rfloor$$
- 当卷积核按步长进行跳跃的时候，如果剩余的像素宽度不足以完整容纳一个卷积核，那么就直接越界的滑动，不计算该位置

### Stride的作用

1. 实现了降采样与特征压缩
   - 以跳跃的方式天然压缩了特征图的大小，降低后续网络层的参数量与显存占用
1. 扩大感受野
   - 步长加快了空间尺寸的收敛，是更深层的单个特征神经元能够俯瞰原始输入中更大范围的语义信息

## 三维卷积

- 卷积核的通道数必须等于输入图像的通道数 -> 与三维图像进行卷积的卷积核必须是三维的

**步骤**
1. 卷积对应相乘
2. 三通道相加
3. 滑动与输出
4. 得到二维特征图（**如果经过多卷积核，就会有多输出通道，也就有三维特征图**）

- 通过调整卷积核在不同通道上的数值，网络可以只关注特定通道的特征 -> 如果只要红色通道的边缘，卷积核中对应绿色和蓝色的卷积核的值就可以为0

## 神经网络的构建

$Z^{[l]}$ = $A^{[l-1]}$ * $W^{[l]}$ + $b^{[l]}$
$A^{[l]}$ = g($Z^{[l]}$)
- 每个卷积核上只有一个偏置

- 在同一个卷积层内，所有的卷积核尺寸默认是完全相同的
	- 如果同一层并排使用不同尺寸的核，可以通过精细设置各个分支的Padding,输出的高和宽强行保持相同

- $n_{c}^{[l]}$为上一层的卷积核的数目

- 经过卷积神经网络，最后的参数经过softmax等激活函数进行判别
- 随着网络层数的增加，通常情况下，特征图的变成会越来越小，通道数会越来越多

### 卷积神经网络的组成

1. 卷积层 -> 特征识别
2. 池化层 -> 客观汇总与筛选
3. 完全连接层：FC

## Pooling Layer(池化层)

- 把前面卷积层提取出来的显著信息保留下来，把多余的空间冗余扔掉

- 卷积层和池化层是“波浪式”交替推进的 -> 多个卷积层后面跟着一个池化层
	原因
	- 保持计算量平衡：
      	随着网络加深，为了提取丰富的语义，通道数会上升 -> 通过压缩高和宽保证计算量维持在硬件可以承受的范围内
    - 逐级扩大感受野
        池化层将空间尺寸缩小后，后面的卷积层看到是比之前更大的范围

1. 最大池化（Max Pooling）
   在[[量化与部署#感受野|感受野]]内取最大值（最显著的特征激活响应）作为输出。
2. 平均池化（Average Pooling）
   在[[量化与部署#感受野|感受野]]内计算所有数值的算术平均值 -> 大幅削减参数

### 池化层的超参数

- 池化层有有且仅有一组固定超参数，没有任何可学习的参数(无法通过梯度下降/反向传播进行修改)
	- f：池化窗口大小
	- s：步长
	- p：填充大小（绝大多数情况下p = 0）
	- 池化类型：Max/Average
*池化层是二维的，不存在通道数*

- 池化层是逐通道独立进行的，输入多少通道，输出多少通道

### 特性

1. 零参数 -> 池化层没有任何权重w,b
2. 平移不变性 -> 如果图像中的特征发生轻微平移、形变或旋转，最大池化仍能够捕捉到该特征的最大激活值，使网络对局部微小绕动更具鲁棒性
3. [[转接文件库#降维|降维]]与计算加速 -> 逐步减小特征图的空间分辨率，有效降低后续卷积层的计算量和内存占用
