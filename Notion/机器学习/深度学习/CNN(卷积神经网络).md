# CNN(卷积神经网络)

**卷积神经网络到底是如何实现分工合作的**

- 在初始化卷积神经网络时，每层被赋予一定的意义
- 网络并不知道各层扮演什么样的角色，而是受限于底层的感受野几何结构，在全局最小化Loss的强烈牵引下，网络自发涌现出自上而下的分层表示

**如果模型中途输出多个结果，梯度下降的实现方法 -> 辅助分类器**

1. 标量化总损失
	- 在执行反向传播的时候，不仅有主输出，还有中间的分支输出，系统会将它们加权合并为总损失（主输出不参与加权）
2. 多路径叠加原理
	- 主干传回来的梯度与中间侧枝直接注入的梯度加权相加（主输出不参与加权）

## 卷积

- 卷积是拿一个小矩阵在另一个大矩阵上按规律滑动、加权相乘并求和的动态计算
- 卷积运算是卷积神经网络的基本组成单元

- 同一个卷积层的宽和高一般是等长的。（一般在高宽比极端的图像中采取非等长卷积核）

### 卷积核大小通常为奇数的原因

- 保证Same卷积的对称性 -> 保证原特征图的填充层数p为整除
- 拥有天然的“中心像素“ 
	- 奇数核拥有唯一的中心点，在计算机视觉中方便把当前卷积计算的结果精确绑定并映射到中心像素的几何坐标上
	- 卷积核通常呈现中心权重最大/最关键，周围权重呈放射或对称衰减

### 使用卷积的原因

**如果将图像转换为向量，扔进神经网络中**
- 参数的数量会极其庞大 -> 内存溢出、计算耗时较大，极易导致过拟合

**使用卷积神经网络**
- 参数共享
	- 如果一个特征检测器如果对图像左上角有效，那么大概率对图像其他区域同样有效
- 连接稀疏性/局部空间相关性
	- 输出特征图中的每一个像素，仅与输入图像对应局部区域相连，而不受整张图像其他无关像素的直接干扰
- 平移不变性 -> 卷积核对整张图片进行平移滑动
	- 如果一个特征能在左上角被检测出，当这个特征平移到右下角时，同样也可以检测出

## 边缘探测

- 卷积不仅能感知边缘的存在，还能分辨边缘的渐变方向。
     若只关心边缘位置，而不关心方向，可通过绝对值操作将其统一

- 通过反向传播与梯度下降，神经网络会自动学习出最适合当前任务的特征提取器 -- 不仅能学会水平和垂直边缘检测，还能自动发现任意角度的边缘，甚至更复杂的纹理和高维模式

## Padding(填充)

### 为什么采取
- 为了放置图像尺寸不断减小 -> 如果没有Padding,深层网络的特征图会迅速缩减为1 * 1，导致无法构建深层神经网络
- 边缘/角落信息严重丢失 -> 导致原图边界处的信息被稀释甚至直接丢弃
	- 角落像素指挥参与一次计算
	- 中心像素会被多次计算

### 解决方式

**常见的卷积选择**

1. Valid -> 无填充 -> 图像每次卷积都会按核大小逐渐缩小
2. Same -> 同尺寸卷积 -> 通过往原图像外围绕$p = \frac{f - 1}{2}$圈0(f为卷积核的边长，且[[CNN(卷积神经网络)#卷积核大小通常为奇数的原因|卷积核大小通常为奇数]])，使卷积输出尺寸与输入尺寸保持严格一致，并且保证了每个像素点都当过中心像素点（确保了真实内容为主体，不会像Full填充一样真实信息被稀释）
3. Full卷积 -> 保证原图像中每个像素点计算次数都相同 -> 源图像往外围绕p = f - 1圈0
	   [[转接文件库#不采用Full填充的原因|不采用Full填充的原因]]

## Stride(卷积步长)

- 卷积核在输入图像上每次滑动的像素间隔跨度
$$\text{输出尺寸} = \left\lfloor \frac{n + 2p - f}{s} + 1 \right\rfloor$$
- 当卷积核按步长进行跳跃的时候，如果剩余的像素宽度不足以完整容纳一个卷积核，那么就直接越界的滑动，不计算该位置

### Stride的作用

1. 实现了降采样与特征压缩
   - 以跳跃的方式天然压缩了特征图的大小，降低后续网络层的参数量与显存占用
1. 扩大感受野
   - 步长加快了空间尺寸的收敛，是更深层的单个特征神经元能够俯瞰原始输入中更大范围的语义信息

## 三维卷积

- 卷积核的通道数必须等于输入图像的通道数 -> 与三维图像进行卷积的卷积核必须是三维的

**步骤**
1. 卷积对应相乘
2. 三通道相加
3. 滑动与输出
4. 得到二维特征图（**如果经过多卷积核，就会有多输出通道，也就有三维特征图**）

- 通过调整卷积核在不同通道上的数值，网络可以只关注特定通道的特征 -> 如果只要红色通道的边缘，卷积核中对应绿色和蓝色的卷积核的值就可以为0

## 神经网络的构建

$Z^{[l]}$ = $A^{[l-1]}$ * $W^{[l]}$ + $b^{[l]}$
$A^{[l]}$ = g($Z^{[l]}$)
- 每个卷积核上只有一个偏置

- 在同一个卷积层内，所有的卷积核尺寸默认是完全相同的
	- 如果同一层并排使用不同尺寸的核，可以通过精细设置各个分支的Padding,输出的高和宽强行保持相同

- $n_{c}^{[l]}$为上一层的卷积核的数目
![[Pasted image 20260906155706.png]]

- 经过卷积神经网络，最后的参数经过softmax等激活函数进行判别
- 随着网络层数的增加，通常情况下，特征图的变成会越来越小，通道数会越来越多

### 卷积神经网络的内部组成

1. 卷积层 -> 特征识别
2. 池化层 -> 客观汇总与筛选
3. 完全连接层：FC

### 卷积神经网络的基础原型的结构 -> LeNet-5

- 卷积层和池化层是“波浪式”交替推进的 -> 一个或多个卷积层后面跟着一个池化层 -> 称为一层
	原因
	- 保持计算量平衡：
      	随着网络加深，为了提取丰富的语义，通道数会上升 -> 通过压缩高和宽保证计算量维持在硬件可以承受的范围内
    - 逐级扩大感受野
        池化层将空间尺寸缩小后，后面的卷积层看到是比之前更大的范围

- 现在多用步长卷积替代池化层

- 最后接上若干个全连接层，最后再输出

## Pooling Layer(池化层)

- 把前面卷积层提取出来的显著信息保留下来，把多余的空间冗余扔掉

1. 最大池化（Max Pooling）
   在[[量化与部署#感受野|感受野]]内取最大值（最显著的特征激活响应）作为输出。
2. 平均池化（Average Pooling）
   在[[量化与部署#感受野|感受野]]内计算所有数值的算术平均值 -> 大幅削减参数

### 池化层的超参数

- 池化层有有且仅有一组固定超参数，没有任何可学习的参数(无法通过梯度下降/反向传播进行修改)
	- f：池化窗口大小
	- s：步长
	- p：填充大小（绝大多数情况下p = 0）
	- 池化类型：Max/Average
*池化层是二维的，不存在通道数*

- 池化层是逐通道独立进行的，输入多少通道，输出多少通道

### 特性

1. 零参数 -> 池化层没有任何权重w,b
2. 平移不变性 -> 如果图像中的特征发生轻微平移、形变或旋转，最大池化仍能够捕捉到该特征的最大激活值，使网络对局部微小绕动更具鲁棒性
3. [[转接文件库#降维|降维]]与计算加速 -> 逐步减小特征图的空间分辨率，有效降低后续卷积层的计算量和内存占用
4. 防止过拟合 -> 通过丢弃部分细微空间信息，起到正则化效果，降低对空间位置细节的过拟合风险

## AlexNet

### 使用ReLU解决梯度消失并加速收敛

- 在使用ReLU之前都是使用的sigmoid或tanh进行激活，但是如果z特别大，激活函数对应位置的导数就特别小，梯度下降速度会特别慢，就会出现梯度消失 -> 使用ReLU将导数固定为1

### 引入Dropout减轻过拟合

- AlexNet仅在全连接层引入Dropout

**原因**
1. 参数分布极不均衡 -> 全网6000万参数，其中超过90%集中在最后三个全连接层
2. 打破特征共适应 -> 全连接层中的每个神经元具备自身独立的作用
3. 卷积层的天然抗过拟合属性 -> 卷积层的参数量较少

## ResNet(残差网络)

- 由于神经网络的层数过多，导致了信号衰减与非线性扭曲，导致神经网络的**优化困难**
- 通过引入**跳跃连接**，彻底打破了传统神经网络由于深度增加带来的“网络退化”(当网络层数增加到一定程度，训练集上的误差不降反增)限制，使得训练上百层甚至上前层的超深神经网络称为可能
- 残差连接是现代深度学习中最常用的方法 -> 深度超过数十层的主流现代神经网络，几乎都内置了残差结构

**克服优化困难的原因** -> 反向传播中新添了加法

- 无残差网络时，优化困难的原因：反向传播都是参数连乘 -> 浅层的卷积核根本接收不到来自最终损失的指导信号，更新步长为0，前几十层完全学不动

- 有残差网络时：
	- 零成本保底：若某几层对网络毫无正向贡献，优化器会让权重衰减至0 -> 自动获得了“随时撤销多余层”的能力
	- 微调器视角：主干x保留并传递了已有的大结构、低频基础特征，中间的残差路径只需专注于学习特征修正量（Δx），大幅度降低了拟合复杂度
- 权重为0时，该层神经元的导数项恒等于1，保留了最后一层的误差信号可以直接无损传递到浅层网络

**意义**

- 集成网络假说：删除残差网络中的某几个残差块看，模型预测性能几乎平滑无损；绝大多数有效路径的等效深度其实只有10~20层
- 损失曲面平滑化：普通的直通网络的损失曲面充满剧烈的断崖与局部极小陷阱，加上残差连接后高维曲面被强行拉平为平缓凸起的“规整碗底”

## 1 * 1卷积

- 1 * 1卷积等价于在每个像素位置上独立应用一个全连接层
- 不改变图像分辨率，仅在跨通道维度上进行特征融合与线性/非线性变换

**起到的作用**

1. 降维与升维
2. 大幅度削减计算量
3. 增加非线性表达能力 -> 1 * 1卷积都会接入ReLU激活函数，在不增大空间感受野的前提下假审网络层数
4. 跨通道信息交互

## InceptionNet(初始网络)

- 在不无限制堆积参数和算力的前提下，把网络做得更深，更宽

- 在设计传统的卷积层时，工程师往往需要艰难权衡超参数
	- 用1 * 1提取跨通道特征？
	- 用3 * 3提取细粒度局部特征？
	- 用5 * 5覆盖更大范围的上下文特征？
	- 用3 * 3最大池化做下采样（降低数据分辨率或采样率的过程）？
- 使用多尺度并行组合在一起（使用Same Padding做到它们的分辨率相同）
	- 如果直接计算而不做控制的话，当前层做5×5卷积本身算力就极为昂贵；而池化等分支拼接后会使输出通道数急剧膨胀，进而导致下一层大卷积核的计算量失控
	- **解决方案 -> 降维**
		- 在3 * 3/5 * 5卷积之前对多维特征图进行1 * 1卷积降维，再进行3 * 3/5 * 5卷积
			- 实行1 * 1卷积并不会将特征图中的特征进行丢失，反而将特征浓缩至低维空间中
				- **流形假设**：高维空间中有效数据，通常几种分布在一个低维的流行曲面上
		- 在进行最大池化后做1 * 1卷积

## mobileNet

- 在保持较高准确率的前提下，大幅削减计算成本与参数量，使其适合部署在移动端和边缘嵌入式设备上

### 深度可分离卷积

- 深度可分离卷积 = 深度卷积 + 逐点卷积

- 深度卷积
	- 每个输入通道单独使用一个二维卷积核进行滤波，只在空间维度上提取特征，不改变通道数
- 逐点卷积
	- 使用1 × 1的常规卷积核，跨通道将上一阶段的特征线性组合，映射到目标通道数

**为什么有效？**

*空间维度*：看一个像素周围的邻居像素长什么样
*通道维度*：看不同通道代表的信息如何组合
*传统卷积*：强制卷积核在空间和所有通道进行同时计算
*深度可分离卷积*：将空间相关性与通道相关性解耦

**mobileNet v2**

**倒残差块 -> 兼顾了低维内占用与高维特征表达能力**
- 1 × 1卷积升维
	- 打开操作空间。低维通道信息太密，容错率太低；把通道拉宽到高维后，网络才有足够的“自由度”去拆解复杂特征，并且在高维下加ReLU不会破快特征流行
- 进行ReLU激活
- 3 × 3深度卷积
	- 极低成本提取空间局部纹理
- 进行ReLu激活
- 1 × 1卷积降维
	- 压缩打包与通道融合，且绝对不加激活函数
- 残差相加
	- 低维主干的高速公路。

**激活函数为什么要去除**

- 高维空间：维度足够宽裕，数据即使去除一部分，剩下的粉量依然有足够的自由度把原本的信息保留
- 低维空间：数据的每个维度都极度紧凑且关键，这种截断是不可逆的坍塌

## efficientNet

- 用一套数学公式，让网络的“深度”、“宽度”和“输入分辨率”按固定比例协同缩放，用最低的算力消耗换取最大的精度收益
	- 深度 -> 能捕捉更复杂的抽象特征
	      -> 层数过深会导致梯度消失、训练困难，后面几层带来的精度提升急剧变小
	- 宽度（通道数） -> 提取更丰富细微的特征，并行度高，易于训练
		  -> 极易导致浅层特征冗余，参数量暴增，且难以捕捉深度高阶特征
    - 输入分辨率 -> 保留更多细节
	            -> 计算量以输入边长的平方级暴涨，且过大的图片输入浅层网络同样无法有效建模全局上下文
- 如果输入分辨率更高，网络必须变得更深才能拥有足够的感受野来覆盖更大区域，同时通道也需要变宽以容纳新增的细微粒特征

## 提高识别率的方法

- 模型集成：独立训练多个神经网络，模型架构或初始化可以不同。测试时将同一张图片送入系统，最后取平均值作为结果
	- 集成多个网络需要消耗更多的显存和计算量，速度也不会太快

- 测试期多区域裁剪：将单张测试图片裁剪出多个版本，然后放分类器上跑，对所有子图预测取平均值
	- 推理时间大大提高

## 目标定位

- 不仅要求判断图中物体的类别，还要用边界框把物体圈出来
- 通常针对图像中只有一个主要目标

**输出向量**$$y = \begin{bmatrix} p_c \\ b_x \\ b_y \\ b_h \\ b_w \\ c_1 \\ c_2 \\ \dots \end{bmatrix}$$
$p_c$表示有无目标物体
c1,c2……表示类别概率

- 当$p_c$ = 0时，其余坐标均无效，只惩罚$p_c$预测误差

损失函数：$$\mathcal{L}(\hat{y}, y) = \mathcal{L}_{conf}(\hat{p}_c, p_c) + p_c \cdot \Big( \mathcal{L}_{box}(\hat{b}, b) + \mathcal{L}_{class}(\hat{c}, c) \Big)$$
### 地标检测

- 将预测单一矩形框的任务，泛化成让神经网络直接回归目标上一系列具有固定几何与语义意义的二维坐标点
- 标签与定义必须全局统一：数据集标签中的位置坐标对应的语义要一致

### 卷积网络上实现滑动窗口

- 将全连接层转化为全卷积层（使用1×1卷积层代替全连接层），让整张大图只需单次前向传播即可并行获得所有滑动窗口的结果
- 输入图像经过卷积神经网络后输出的特征图中的每一个位置，直接对应原图上某个步长滑动窗口的分类与定位结果
- 原图各窗口重叠区域的特征梯度过程被卷积计算天然共享，不再重复执行

**相比于传统切割图像，直接在CNN上使用滑动窗口的优势**

- 极高的计算效率，避免了对重叠像素的重复计算
- 零内存裁剪开销：在边缘端对图像做频繁的剪切会极大的消耗CPU/DLA调度资源
- 支持任意尺寸输入：代码和网络结构不用变，整张大图直接Resize/不Resize都能送进去跑。只是最后输出的尺寸大小有所不同（等于裁剪后的图像对应的位置结果）

## YOLO

**滑动窗口痛点与解决思路**
- 滑动窗口使用固定尺寸的窗口逐行遍历图像，尺寸巨大，且边界框的位置受限于窗口尺寸，无法完美拟合形状各异的物体，并且当物体不在窗口内，则无法识别该物体
- 将图像网格化与卷积网络结合，让神经网络直接回归预测具体的边界框坐标，实现端到端的单次前向传播预测

**标签分类**
- 在模型训练的时候，我们输入数据集，算法会根据[[转接文件库#YOLO输入框的分配策略|分配策略]]匹配这个物体对应的是哪个框框

**网格划分与目标分配**
- yolo下采样分为8倍、16倍、32倍
	- 8倍下采样负责识别小目标
	- 16倍下采样负责识别中目标
	- 32倍下采样负责识别大目标
- 每个物体的中心点落在哪一个网格内，该物体就由这个网格负责预测
	- 在引入多尺度预测后，同一物体可能在不同的特征尺度上，被分配到多个网格中
	- 在训练的时候会根据物体在图片中的大小分配对应的网格（小物体分配给小网格，大物体分配给大网格）
	- 在推理的时候重复框会由NMS最终合并

**标签向量输出**
每一个网格对应一个输出向量$$y = [p_c, b_x, b_y, b_h, b_w, c_1, c_2, c_3, \dots]^T$$
($b_x$,$b_y$):边界框中心点相对于当前网格左上角坐标的相对位置，且$0 \leq b_x, b_y \leq 1$
($b_h$,$b_w$):边界框的高度与宽度相对于当前网格大小的比例。$b_h$,$b_w$数值可以大于1

### 并交比（IoU）

- 作为一个检测标准，判断目标定位算法是否准确
- 目标框与预测框的交集 / 目标框与预测框的并集
	- IoU的取值范围在[0,1]之间。完全不重叠为0，完全重合为1
	- 一般大于0.5为合格

#### NMS（non-max suppression）

+ 当网络内预测出多个重叠的候选框时，算法会先保留置信度最高的框
	+ “多个重叠的候选框”是因为同一个物体的特征覆盖了邻近的多个网络，导致相邻的网格“误以为”目标中心在自己这里，进而都对该物体输出了预测框
+ 随后计算其余候选框与该最高分框的IoU，若IoU > Threshold,说明他们检测的是同一目标，直接将其删除

**决定框是否精准的因素**

- 训练时的正负样本分配
	- 中心归属法则：只有包含物体中心点的那个网格，才会被标记为正样本
		- 损失惩罚：非中心网格如果试图预测该物体，它的置信度会被反向传播强烈惩罚
	- 让真正的中心网格学会输出接近1.0的高置信度，而边缘网格输出的置信度极低
- 边界框回归损失
	- 模型通过CIoU Loss或DIoU Loss直接对框的位置坐标与真实框做梯度更新
- 感受野质量
	- 越靠近物体中心的网格，其卷积感受野捕获到的”全局特征“越完善，位置回归参数计算出的IoU越高

### Anchor box(先验框/锚框)

- 预先设定的不同比例的模板框
	- 目标框框可能不是正方形，可能是瘦长框，也可能是宽扁框
	- 设置Anchor使单网格具备了捕捉不同形状/宽高比物体的能力

- 原始网格负责确定物体的位置中心
- Anchor Box负责提供物体的初始形状参考，最终预测出的形状是经过模型微调拉伸后的真实形状 -> 模型预测出的最终形状可以是任意尺寸和比例的（并不是提前预设好的形状）

- 当无Anchor Box时：每个网格输出的是$y = [p_c, b_x, b_y, b_h, b_w, c_1, c_2, c_3]^T$
- 当有Anchor Box时：每个网格输出的是$y = [y_{\text{anchor1}}, y_{\text{anchor2}}]^T$
	- 训练阶段：每个真实边界框不再仅仅分配给网格，而是分配给最满足[[转接文件库#YOLO输入框的分配策略|分配策略]]的Anchor Box
		- 最接近目标的Anchor Box的$P_{c}$设为1，其余全设为0
	- 预测阶段：最接近目标真实形状和位置的那个Anchor Box，其对应的$P_{c}$（存在目标置信度）通常最高

**yolo模型看一眼就能得出目标物体的位置，而网格与Anchor Box是认为设计的参考物与输出约束框架**

## RPN(区域推荐网络)

- 通过神经网络自动、高效地筛选出可能包含目标的候选区域，彻底解决传统目标检测在候选框提取上的性能瓶颈

**过程**

- 将经过CNN输出的特征图进行卷积处理，之后进入两个分支

- 分类分支：输出2k个得分，判断Anchor是前景还是背景
- 回归目标：输出4k个位置偏移量，对预设的Anchor的边界进行精细微调

- 根据分类得分提出背景框和分数极低的Anchor
- 应用回归偏移修正剩余Anchor的坐标
- 使用NMS消除高度重叠的冗余框
