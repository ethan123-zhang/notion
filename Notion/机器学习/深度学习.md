# 深度学习

> 神经网络与深度学习。逻辑回归 = 激活函数为 sigmoid 的单个神经元，其详细讲解在 [[经典机器学习]]。
> 相关笔记：[[机器学习指引]] · [[经典机器学习]] · [[量化与部署]] · [[vision/C++ YOLO]]

## 1. 神经元

- 神经元（逻辑回归单元）：相当于「微型决策器」
- 逻辑回归相当于采取特定激活函数的单个神经元
- 接受外部（或上一层神经元）的多个数据输入，分配权重：输入 × 权重 + 偏置（b），结果放进激活函数

> 因为「单个神经元」的数学结构恰好就是逻辑回归，深度学习课常从逻辑回归讲起。逻辑回归的详细内容见 [[经典机器学习]]。

## 2. 神经网络的组成

1. **输入层**：最开始输入的那一层，输入的 x 值
2. **隐藏层**：中间的所有层。只看输入输出，看不到中间层节点的真实值，所以叫隐藏层
3. **输出层**：最后一层，输出的 y 层

计算层数时不计算输入层：**层数 = 隐藏层层数 + 输出层层数**。

### 多层感知机（MLP）
- 输入层（原料）→ 隐藏层 → 输出层（结果）；各层均只有一个
- 网络层数往往包含隐藏层和输出层（不包含输入层）

## 3. 基本概念

- **token**：把人类语言翻译成机器能懂的「数字编号」（或反过来的）中间形态
- **层（神经网络层/密集层）**：一组神经元，以相同或相似特征作输入，依次输出数字
- **激活**：神经元向下游其他神经元发送高输出的程度，本质是决定「要不要把收到的信号传递下去、传多强」

## 4. 激活函数

### 种类
1. **sigmoid**：输出范围 (0,1)，压缩成概率。用于二分类，**永远不要用除非输出层且做二元分类**
2. **tanh(z[i])**：范围 (-1,1)，替代 sigmoid 的最好选择
   - sigmoid 和 tanh 的缺点：z 很大或很小时梯度下降速度特别慢
3. **ReLU（原始）**：x = max(x,0)，最常使用；输入持续为负时梯度恒为 0，神经元永久失活
4. **Leaky ReLU**：x = max(x,αx)，给负输入保留极小斜率，避免神经元完全失活
5. **Softmax**：将所有结果压缩成 0~1 概率且和为 1，用于多分类
6. **Step**：结果 >0 输出 1，<0 输出 0
7. **线性激活函数**：g(z) = z，用于回归问题，结果可正可负

**隐藏层通常用 ReLU**（比 Sigmoid 快）；输出层按任务选（二分类 sigmoid、多分类 softmax、回归线性）。

### 为什么 tanh 优于 sigmoid
1. **「零均值」让下一层学习更快更稳**：
   - Sigmoid 输出范围 (0,1) 永远为正，导致反向传播计算权重梯度时，所有权重更新方向必须「同正或同负」（前提上一层数据也经过 sigmoid），收敛时出现 Z 字震荡、速度极慢
   - tanh 输出 (-1,1) 有正有负、均值接近 0，下一层输入天然具备「数据归一化」效果，梯度更新方向不互补锁死，优化路径更平滑快速

### 为什么要使用非线性激活函数
如果没有非线性激活函数，多层神经网络在数学上等价于单层线性模型，深度失去所有意义。
- 非线性激活函数为每层注入「弯曲空间」能力，让网络足够深或宽就能拟合任意复杂非线性函数
- 线性激活函数几乎只能出现在回归预测任务的输出层

### 单个逻辑回归单元的局限
一个逻辑回归单元只能在空间中画出一条直线边界。判断「这张图是不是猫」时单个逻辑回归单元无法解决。

**深度学习的本质**是把成千上万个逻辑回归单元像乐高积木一样分层连接：
- 浅层神经元：识别简单边缘和线条
- 深层神经元：把浅层提取的线条组合起来，识别猫的部位
- 输出层：汇总所有特征，给出最终分类概率

## 5. 前向传播与反向传播

- **前向传播（推理/预测）**：模型用现有知识（当前权重 w、偏置 b）处理输入并给答案。数据像水流单向穿过网络，经一系列矩阵乘法和激活函数，最终在输出层给结果
- **反向传播（学习/纠错）**：训练阶段专属。先前向传播得预测，与真实情况对比算误差，再用链式法则对每个权重 w 从输出层反向逐层计算梯度，最后用梯度下降等优化算法微调权重

前向传播构架中，初始阶段有很多隐藏单元，随接近输出层数量减少。

## 6. 全连接层

全连接层描述局部神经元交织的密集程度。叫全连接是因为当前「每一个」神经元都与上一层「每一个」神经元有连接。

单个神经元精确计算：
```
a1_1 = g(w1_1 * a0_1 + b1_1)
```
- 特征评估（加权）：w * x（评估当前输入特征的重要性）
- 阈值平移（偏置）：+ b（调整激活难易程度）
- 非线性映射（激活）：g(...)（打破线性死板，拟合复杂规律）

神经网络向量化是为了加速计算。

## 7. 损失函数的种类

1. **均方误差函数（MSE）**：用于回归问题，预测连续具体数值。计算预测值与真实值差值的平方衡量误差
2. **二元交叉熵函数**：用于二分类，预测离散类别概率（非黑即白）。输出通常经 Sigmoid 压缩到 0~1，代表正类概率
3. **稀疏分类交叉熵函数**：二元交叉熵的泛化，用于多分类

> 损失函数只定义在输出层，中间的隐藏层没有独立损失函数或损失值判断。

## 8. 模型训练中的数据加载与喂入

1. 先将数据转成张量或 Numpy 数组
2. 喂给模型：
   - 数据量小：**全批次**，所有样本一次性喂入
   - 数据量大：**小批次**，切成固定大小的「小块」（如 batch_size=32）：
     ① 模型先吞下 32 张图片 ② 显存刚好装下、GPU 并行同时处理 ③ 算这 32 张平均误差后更新一次 ④ 再吃下个 32，直到所有数据看完

## 9. 模型参数与超参数

- **模型参数**（权重 w、偏置 b）：在训练集上通过计算图、反向传播、梯度下降自动算出并不断修正的值
- **超参数**（学习率、网络层数、正则化系数）：模型无法自己算，必须手动填入

## 10. 计算图

计算图是一张数学公式的「流程图」，把复杂公式拆成简单运算。
- 节点 → 数据（x,w,b）或操作符（×）
- 边 → 数据流向
- 前向传播：数据顺箭头一步步加工，吐出预测结果
- 反向传播：根据误差调节参数，对每个参数求偏导，把计算图反过来走、按链式法则求微分（如求每个参数与 J 的关系）

### 参数 w,b 修改的过程
1. 前向传播，根据 w 算预测值
2. 计算损失函数
3. 反向传播，通过偏导数和链式法则计算 J 与各参数关系，算出梯度
4. Adam 拿到梯度，计算更新公式
5. 循环调节直到 w 调整到最优

## 11. 权重随机初始化

权重必须随机初始化，不能统一初始化为 0：
- 权重都相同则同一层每个神经元被赋予的意义完全一样
- 反向传播时神经元收到完全一致的梯度，无论迭代多少次，同层神经元都做相同计算，实际能力相当于一个神经元

## 13. 训练的数据

**分类**：
1. **训练集**：用于训练模型参数（W,b）
2. **交叉验证集/开发集**：用于评估不同算法、调整超参数、选择最优模型架构
3. **测试集（可以没有）**：仅用于评估最终模型的泛化能力。若不需要完全无偏的性能评估，测试集并非绝对必需

**划分比例**：
- 数据量较小（100~10000）：6:2:2 / 7:3
- 数据量较大（1000000+）：98:1:1

**黄金法则**：开发集与测试集必须来自同一数据分布。
- 若训练集和开发集不匹配且效果差，如何判断过拟合还是数据不匹配？引入**训练-开发集**（从训练集随机抠一小部分，不参与训练，专门评估）：
  1. 训练集误差与训练-开发集误差差异大 → 过拟合
  2. 训练-开发集与开发集误差差异大 → 数据不匹配

## 14. 偏差、方差

- 训练集误差小、开发集误差大 → **高方差**
- 训练集误差大、开发集误差小且相差很小 → **高偏差**
- 训练集和开发集误差都很大且相差很大 → **高方差和高偏差**
- 两者误差都很小 → 低偏差和低方差

- **高偏差** = 训练集误差与贝叶斯最优误差（人类水平）的差距 → 增加模型复杂度/提升表达能力
- **高方差** = 开发集误差与训练集误差的差距 → 降低模型复杂度/增加泛化约束

**解决高偏差**：
1. 增加特征数量与构建新特征
2. 选更复杂（增加复杂度）或表达能力更强的模型
3. 减小正则化参数（λ）
4. 训练时间增长/调整优化算法

**解决高方差**：
1. 获取更多训练数据
2. 减少特征数量/特征选择
3. 增大正则化强度
4. 降低模型复杂度
5. 训练时间降低

注意：增加训练数据对高偏差无效（模型容量不足，喂再多数据也无法拟合）；增加特征对高方差有害（特征越多参数空间越大，更易过拟合）。

### 用 Jtrain / Jcv 判断（线性/逻辑回归）
- Jtrain 大、Jcv 大 → 欠拟合（增加特征、加多项式特征、减小正则化）
- Jtrain 小、Jcv 大 → 过拟合（增加数据、减少特征数、增加正则化）
- Jtrain ≈ Jcv 且 Jtrain 较高 → 高偏差 → 欠拟合
- Jtrain << Jcv 且 Jtrain 较低 → 高方差 → 过拟合

- **多项式度数 d**：d 越低易欠拟合，d 越高易过拟合
- **正则化 λ**：λ 特别大 → 参数接近 0 → 高偏差 → 欠拟合；λ 特别小 → 高方差 → 过拟合

### 神经网络训练方法
1. 先判断模型在训练集是否表现良好，不好就增加神经网络
2. 表现良好再判断在交叉验证集是否良好，不好就增加数据量

### ML 开发的迭代循环
1. **选择架构**：按任务决定数据、特征、超参数、模型架构，设定初始框架
2. **训练模型**：把数据喂给模型训练，得出初步结果
3. **模型诊断**：通过偏差、方差和误差分析，找出当前问题

### 增加数据
不要盲目增加所有数据，要针对模型弱点「缺什么补什么」；可通过修改、扭曲数据（仍类似测试集数据的方式）增强。

## 15. 正则化

> 防止过拟合。常见手段：L1/L2、Dropout、数据增强、早停。

### L2 正则化
目标：不直接丢掉特征，而是惩罚过大的参数值，让模型平滑、简单，防止过拟合。
- 通常在代价函数后加上参数 w 的平方和惩罚

![[image 8.png]]

λ（正则化参数）：控制拟合效果与模型简单度之间的权衡。
- λ = 0：无惩罚项，模型拼命拟合每个点，易过拟合
- λ 适中：平衡拟合误差与模型简单度，刚好拟合
- λ 过大：所有权重 w≈0，导致 f(x)≈b，欠拟合

### L1 正则化
将起到微小作用的参数直接删除（而 L2 是把它设成很小的数）。单个微小权重不起决定作用，但多个微小特征同时产生微弱信号时能帮分类；在深度学习和计算机视觉中，100 个 1% 帮助的微小特征往往比 1 个 100% 帮助的绝对特征更鲁棒。

正则化作用（通常只正则化 w1..wn，不正则化 b）：
1. 鼓励学习算法缩小参数值，而不一定要求精准设零
2. 保留所有特征，只防止特征产生过大影响导致过拟合

### 随机失活（Dropout）
目的：专为神经网络设计的正则化技术，解决训练集表现完美、测试集表现拉跨的过拟合。
- 不让每个神经元「摸鱼」，也不让任何神经元「独揽大权」

过程：训练每个 batch/迭代步中以概率 p 随机「切断」当前层一部分神经元的连接（输出强行置 0）；每层设置保留概率，防止一层全失活。让剩余神经元参与当前前向计算与反向传播。

原理：
1. 单个神经元不确定上游某特定神经元是否在线，不会把输入全压在某神经元上，被迫把权重平摊给所有输入（类似 L2）
2. 测试阶段，全部神经元的大网络做一次前向传播，输出近似等价于之前随机失活的子网络各自预言后取几何平均

| 神经元规模 | 保留率 |
| --- | --- |
| 极多 | 0.5 |
| 中等 | 0.7~0.8 |
| 较小 | 0.9~1.0 |

形成的效应：
- 宏观：经过成千上万次随机洗牌，同层任意神经元都被迫变得极其通用，无法与特定神经元搞「小团体绑定」
- 数值：每次搭档不确定，反向传播梯度在不同方向互相拉扯抵消，权重绝对值无法无限制膨胀，整体向 0 收缩，达成极佳正则化效果

### 数据增强
核心思想：缓解过拟合最直接的方法是增加训练样本，但收集新标注数据成本极高。数据增强通过对现有数据做保真变换人工扩充数据集。
- 几何变换：随机水平翻转、随机裁剪、轻微旋转
- 形变与失真：轻微光学扭曲、颜色抖动

作用：迫使深度学习不受位置、方向或轻微形变影响的不变性特征，以极低成本为模型添加泛化正则化约束。

### 早停法
同时监控训练集误差与开发集误差。
- 随迭代增加 J 通常单调递减；开发集误差先降后升（「U 型」拐点）
- 在验证集误差达最低点时终止训练

注意：早停可能导致模型尚未把训练集拟合到最优就提前停止。深度学习调参提倡**正交化**——把「优化损失函数」与「防止过拟合」分开独立调节。

## 16. 归一化输入

将数据预处理为**零均值化**和**方差归一化**。
- 均值解决「偏移中心」问题
- 方差解决「信号强度（振幅/剧烈程度）」问题

注意：测试集必须用训练集计算出的 μ 和 σ² 归一化，绝不能重新计算。

归一化后特征处于相似尺度，损失函数等高线接近对称圆形/同心圆，梯度方向直接指向全局最优点，可用更大学习率 α 大幅加速收敛。因为不再有极端陡峭方向引发震荡，系统对步长的容忍度大幅提升。

## 17. 梯度下降优化
### 梯度消失与梯度爆炸

深层神经网络训练中最核心的数值稳定性问题。
- **梯度消失**：反向传播中连乘项普遍 <1，随层数 L 加深，浅层参数梯度呈指数级衰减至接近 0，浅层权重几乎不更新，深层退化为只有最后几层在有效学习
- **梯度爆炸**：连乘项普遍 >1，梯度指数级爆炸式增长，参数更新幅度极大

#### 解决方案 - 深度网络权值初始化
解决原理：输入特征数量越大，每个参数对应权重值相应减小。
- Var(W) 正相关 1/n[l-1]：权重初始化所用随机分布的方差设为上一层神经元数量的倒数
- 神经网络中均值早被锁死在 0，真正会失控爆炸或消失的是方差

局限性：只能保证初始化瞬间，一旦开始训练，方差就会发生偏移。

### 梯度检查

利用微积分中的双边差分近似值（数值梯度），与反向传播计算出的解析梯度进行比对(比对方法是欧氏距离比)，若两者极其接近，则说明反向传播的代码没有bug

#### 注意事项
- 不要在训练中使用梯度检验，而是仅仅在调试时使用（要不然训练速度太慢了）
- 如果梯度检查算出来相对误差较大，说明反向传播代码中至少有一个导数公式写错了 -> 可以利用展平向量的索引映射，顺藤摸瓜定位到具体的某一层，某一个矩阵
- 记得包含正则化项 -> 如果在计算损失函数时包含了L2正则化，那么在计算J(θ)的数值梯度时也必须加上正则化损失
- 不能直接与Dropout同时使用 -> Dropout会在每次前向传播时随机丢弃节点，导致出现错误
- 有时候网络在初始化附近（参数接近0时）反向传播看起来正常，但随着参数变大才暴露出来Bug。如果怀疑有隐形问题，可以在网络训练几轮后再进行梯度检查

### 加速梯度下降的算法

#### 小批量梯度下降

在一个 Epoch 内，先将训练集数据随机打乱并切分成若干个 Mini-batch，依次在每个小批次上计算梯度并更新模型参数。
- 上标小括号(i):表示第i个样本
- 上标中括号【i】:表示第i层神经网络
- 上标大括号{i}:表示第t个mini-batch

单个Epoch的执行过程：
1. 打乱数据集：必须先对(X,Y)进行同步随机打乱，打破样本间的顺序相关性
2. 将打乱后的数据切成若干大小为B的X{t},Y{t}
3. Loop更新参数

- B = m(全部样本)  ->  遍历完整个数据才更新一次参数
	- 每次迭代花费时间太长
	- 数据量过大可能会出现内存溢出
- B = 1(单个样本)  ->  每看完一个样本就更新一次参数
	- 失去向量化优势
	- 受噪声影响，震荡极其剧烈
- 1 < B < m -> 每看完一次mini-batch就更新一次参数
	- 具备向量化优势
	- 不需要看完所有训练集才更新参数
	- 虽有噪声影响，但是波动不是特别剧烈

选择小批量梯度下降的时机：
-  如果训练集较小（m < 2000）就没必要使用小批量梯度下降了，直接看完所有数据再更新参数
-   如果训练集较大，可以进行小批量梯度下降
      B的选择要是2的幂次 -> 确保每个批次符合CPU/GPU的构造 

#### 指数加权平均

通过平滑历史梯度波动，过滤高频噪声，从而加速训练并抑制震荡
- Vt = βVt-1 + (1-β)θt

偏差修正：当初始化v0 = 0时，前几步计算会出现严重偏低（冷启动偏差） -> 需要在迭代过程中将vt除以(1 - β的t次方)
- 在深度学习训练中，绝大多数优化器在经历数十轮迭代后偏差迅速归零，因此常省略偏差修正

##### Momentum(动量梯度下降)

将指数加权平均直接作用于一阶梯度dW
- Vdw = βVdw + (1-β)dW
- W = W - α * Vdw
纵向（震荡剧烈方向）正负梯度在滑动平均中相互抵消，振幅减小
横向（目标方向）梯度持续同向累加，速度加快
- 速度加快是因为震荡幅度降低，可以适当调高学习率导致的横向速度加快

##### RMSprop(均方根传播)

根据历史振幅（二阶动量），给每个参数定制专属的学习率

1. 先测量每个参数的历史振幅（带平方是为了消除负数的影响）
   ![[Pasted image 20260828192214.png]]
2. 用均方根去”除“当前梯度（ε是极小值，用来防止分母为0）
   ![[Pasted image 20260828192320.png]]

梯度下降场景的变化对学习率的影响：
- 平缓 -> 陡峭：平方项数量级压制，一步瞬间感应，刹车极快
- 陡峭 -> 平缓：衰减因子慢慢稀释，存在明显的之后效应

缺陷：RMSprop对于梯度变化大做出的学习率降低的操作是具备一定局限性的 -> 即使是横向（瞄准目标方向）的路是陡峭的，RMSprop依旧是一棍子打死，学习率降低

##### Adam

将动量梯度下降用于平滑梯度、更新方向，把RMSprop用于对各维度的自适应调节学习率

#### 学习率衰减

在使用mini-batch梯度下降的时候，每个batch仅包含部分样本，梯度计算带有噪声
- 固定较大的学习率α：训练初期能快速靠近最优区域，但在后期，梯度噪声会导致参数在全局最小值附近不断震荡，无法稳定收敛到更小、更精确的最优点
- 引入学习率衰减：训练初期保持较大步长快速探索，后期逐步减小步长，使更新步伐变得细腻，最终在全局最优解附近紧密收敛
![[Pasted image 20260828201239.png|488]]


- 梯度下降中，学习率衰减和Adam都能控制学习率的大小，如果同时使用这两个算法的话，就需要在adam调整学习率的基础上进行学习率衰减操作

### 局部最优

在高维参数的神经网络中，遇到”深坑“这种局部最优的概率极低。往往是遇到鞍点和平缓高原
- 鞍点周围的高原地区的梯度近似为0，导致参数更新的步伐极其微弱，需要大量时间才能走出平坦区

## 18. 参数调整

### 超参数调整优先级

1. 学习率α
2. 动量梯度下降系数β、隐藏单元数量、mini-batch大小
3. 网络层数、学习率衰减率
4. 通常固定的/较少调优的参数 -> Adam优化器的β1，β2，ε

### 采样与搜索策略

1. 随机采样而非网格搜索 -> 不知道按个超参数对结果更关键。网格搜索会在不重要的参数上浪费大量重复评估，而随机采样能覆盖更多重要参数的不同取值点
2. 由粗到精
     - 先在广阔的参数空间随机采样
     - 发现表现优秀的高性能区域后，缩小范围聚焦该子空间，进行高密度的随机采样

### 选择合适的标尺和尺度

不能简单地在线性尺度上均匀采样，而应根据超参数的物理意义原则尺度

1. 线性尺度采样
	- 适用于神经元数量和网络层数
2. 对数尺度采样
	- 学习率 -> 学习率的取值通常是在[0.0001,1]，应在指数尺度上采样，确保各数量级有相同的概率
		- 如果采用线性取值，[0.1,1]上取值的概率为0.9（通常使用效果会更差），其余的值的概率为0.1（通常使用的效果会更好）
	- 指数加权平均β -> β通常取值[0.9,0.999],1 - β取值为[0.001,0.1],再取对数
		- k = 1/(1-β) -> β表示的时衰减率，k表示的是历史记忆长度/平滑窗口
		- 当β -> 1时，β的微小线性变化会导致k发生非线性的阶跃式暴增

### 训练与调优范式

1. 算力匮乏、模型巨大 -> 一次只能跑一个或极少模型 -> 细心照料单一模型，随训练曲线手动微调超参数 -> 观察Loss曲线，动态调整
2. 算力充沛 -> 同时并行启动几十/上百个不同超参数的模型，各跑各的 -> 最终对比各个模型验证集表现，选出最优解

### batch norm(批量归一化)

- 在隐藏层的上一层进行归一化操作
- 与输入归一化不同的是，批量归一化可以通过z(i) = γz_norm(i) + β调整均值和方差
- 神经网络如果使用批量归一化，那么在z[l]经过激活函数前要进行批量归一化操作
- 在batch norm中，偏置项b[l]在做减去均值的归一化操作时被完全抵消了，而BN自身的参数β[l]已经完美接管了偏置的功能

## 18. TensorFlow 模型训练步骤

### 1. 指定如何计算输出（给定输入 x 和参数 w,b）
```python
layer_1 = Dense(units=25, activation="relu")  # 隐藏层1，units 为隐藏单元数
layer_2 = Dense(units=15, activation="relu")
layer_3 = Dense(units=1, activation="linear")
model = Sequential([layer_1, layer_2, layer_3])  # 连接三层，方便训练
```

### 2. 指定损失函数和成本函数
```python
model.compile(loss=BinaryCrossEntropy(from_logits=True))
# BinaryCrossEntropy：二元交叉熵
# from_logits=True：输出层仅用线性激活（linear），把激活 1/(1+e^z) 和交叉熵损失放入规范中
#  -> 降低数值取舍误差，计算更准确
```

### 3. 最小化成本函数
```python
model.fit(x, y)  # 开始训练，epochs 表示训练次数
```

### 4. 放入新数据试试效果
```python
raw_predictions = model.predict(x_new)  # 获取模型吐出的值
probabilities = tf.nn.sigmoid(raw_predictions)
```

### 5. 查看之前训练的数据
```python
logit = model(X)        # 输入训练好的模型，获取原始输出（linear 激活）
f_x = tf.nn.sigmoid(logit)  # 手动将原始输出经 Sigmoid 转换
```

### from_logits 设为 True 时的注意事项
需将最后一层隐藏层激活设为 linear，训练过程改变：
1. 模型像做题学生，输入是考题，激活函数最后吐出的值（linear）是答案
2. 因用二元交叉熵 + from_logits=True，老师把学生算的数经二元交叉熵
3. 结果和标准答案比对，得误差，改权重 w 和 b
   
## 20. 卷积神经网络（CNN）

一个神经网络中有多个卷积层。

### 卷积的作用
- **一维卷积**：处理序列数据（传感器信号、自然语言、音频波形）
- **二维卷积**：处理网格状数据（传统图像、音频频谱图）
- **三维卷积**：处理立体或时空数据（视频动作识别、医疗立体影像）

### 全连接层和一维卷积层的差异
1. 全连接层一次性看完全部输入，一维卷积层用小窗口一段一段看
2. 全连接层打乱输入顺序结果相同（不具备时序性）；一维卷积层强依赖排列顺序，专门捕捉相邻数据规则
3. 全连接层每个输入对应独立权重；一维卷积层同一个滑动窗口共用同一套权重
4. 全连接层把提取好的高级特征做最终综合打分/分类；一维卷积层从原始序列信号提取特定规律

只要适当使用正则化，几乎永远不会因用更大神经网络而受伤害；但更大神经网络可能减慢算法速度。

## 21. 迁移学习

迁移学习：把「任务 A」学到的知识迁移到「任务 B」，节省在 B 上学习的时间和成本。
- 监督预训练是为了获得拥有强大通用基础能力的「大脑」
- 官方监督预训练 → 自己的针对性微调 = 一次成功的迁移学习实践
- 用处：学习猫狗汽车人后，学到图像输入层的合理参数集，转移到新网络时从更好起点开始，只需稍加学习就有望达到相当好的模型
- 监督预训练和微调的数据关系：底层格式（模态）必须一样，具体内容（领域）通常完全不同
- 微调数据集比预训练数据集小很多

## 22. 模型评估（补充）

### 判断模型是否合格
1. 数据分训练集、交叉验证集、测试集
2. 比较 Jtrain 和 Jcv（见「偏差、方差」一节）

### 判断模型实际水平（逻辑回归）
1. 设立概率阈值（如 0.5），预测对记 0 误差、错记 1 误差，算总错误率

### 模型选择与训练
训练集让模型自己看题、反向传播修正底层权重；交叉验证集让工程师观察模型状态、手动调超参数再重训；测试集判断模型真正水平。

### 机器学习项目完整周期
1. 确定项目范围 → 2. 收集数据 → 3. 训练模型、错误分析、迭代升级 → 4. 模型部署
