## 学习阶段划分

### 阶段 1：模型通用中间件（ONNX）

- **核心目标：** 掌握模型跨平台转化的标准中间件结构。
    
- **主要技能与知识点：**
    
    - 使用 PyTorch 导出标准的 `.onnx` 模型文件。
        
    - 使用 `onnx-simplifier` 进行算子融合与计算图优化。
        
    - 使用 Netron 可视化查看计算图，分析动态/静态 Batch 与算子兼容性（Operator Support）。
        

### 阶段 2：Jetson Nano 侧 —— TensorRT 与量化基础

- **核心目标：** 理解 GPU 加速原理与 TensorRT 的量化校准（PTQ）流程。
    
- **主要技能与知识点：**
    
    - 使用 TensorRT `trtexec` 工具完成 `ONNX -> TensorRT Engine` 的转换。
        
    - 掌握量化校准集（Calibration Dataset）的制作与 KL 散度（Entropy Calibration）算法。
        
    - 使用 C++ / Python 调用 TensorRT API 实现推理，理解显存分配（`cudaMalloc`）与异步数据流。
        

### 阶段 3：鲁班猫 5（RK3588）侧 —— RKNN-Toolkit2 与硬件级 INT8

- **核心目标：** 掌握 NPU 离线编译、混合精度量化与板端 C++ 部署。
    
- **主要技能与知识点：**
    
    - 使用 `rknn-toolkit2` 完成模型转换、Simulator 仿真与**逐层精度分析（Accuracy Analysis）**。
        
    - 掌握对称量化/非对称量化，以及敏感层保护（部分层保留 FP16，其余做 INT8）。
        
    - 编写 **RKNN C++ API** 结合 **Zero-Copy（内存零拷贝）** 机制提升推理吞吐量。
        

### 阶段 4：双板协同与端侧大模型（LLM）探索

- **核心目标：** 打通“CV 边缘检测 + 边缘通信 + 端侧 LLM”全栈流程。
    
- **主要技能与知识点：**
    
    - 使用 **RKLLM 工具链** 完成小语言模型（如 Qwen2-1.5B）的 4-bit（W4A16）量化与转换。
        
    - 掌握边缘设备局域网通信（MQTT / HTTP REST API）。
        

## 硬件与生态对比表

|**维度**|**Jetson Nano B01 (Sub)**|**鲁班猫 5 (RK3588)**|
|---|---|---|
|**芯片架构**|NVIDIA Maxwell GPU (128 CUDA cores)|Rockchip RK3588 (4×A76 + 4×A55, 6 TOPS NPU)|
|**核心部署工具**|TensorRT (CUDA 生态)|RKNN-Toolkit2 / RKLLM (NPU 生态)|
|**推荐量化精度**|**FP16**（无硬件 INT8 Tensor Core）|**INT8**（原生硬件 NPU 加速）|
|**内存架构**|4GB LPDDR4（CPU/GPU 共享内存）|8GB/16GB LPDDR4x/5（CPU/NPU 共享内存）|
|**部署语言/接口**|C++ / Python (TensorRT API)|C++ (RKNN C API / Zero-Copy) / Python|

## 实践项目清单

### 项目 1：YOLOv8/v11 跨平台 Benchmark 对比

- **项目描述：** 在两块板子上分别部署同一个 YOLO 目标检测模型，输出性能与精度对比报告。
    
- **关键步骤：**
    
    - **Jetson Nano：** 对比 FP32、FP16、INT8 精度下的 Latency (ms) 和 mAP 变化。
        
    - **鲁班猫 5：** 使用 `rknn-toolkit2` 导出 INT8 模型，测试 NPU 占用率与 FPS。
        
    - **最终产出：** 《Jetson TensorRT vs Rockchip RKNN 量化性能与精度损耗分析报告》。
        

### 项目 2：鲁班猫 5 多路 RTSP 智能安防系统

- **项目描述：** 利用 RK3588 的硬件编解码能力处理 2~4 路视频流并进行实时 NPU 推理。
    
- **关键步骤：**
    
    - 使用 MPP (Media Process Platform) 与 RGA (2D Acceleration) 进行硬件级解码和 Resize。
        
    - 通过 Zero-Copy 将图像帧推给 RKNN 模型的 3 个 NPU 核心并发推理。
        

### 项目 3（双板协同）：分布式视觉预警与端侧 LLM 网关

- **项目描述：** 双板通过局域网组网，Nano 负责视觉事件触发，鲁班猫 5 负责 LLM 文本分析。
    
- **关键步骤：**
    
    - **Jetson Nano：** 运行轻量级检测模型，识别特定异常事件后打包为 JSON/HTTP 请求发送。
        
    - **鲁班猫 5：** 板载 **RKLLM** 部署 **Qwen2-1.5B (4-bit)**，接收请求后输出结构化诊断报告。
