# 量化与部署

## 量化

### 是什么?

- 量化是指将高精度的浮点数表示为压缩为低精度的定点整数表示(FP32 -> INT8)的过程,用于降低模型内存占用,实现硬件加速.量化带来的误差叫量化误差
- 保持数值相对分布与动态范围不变的离散化映射机制

- 模型的量化是对权重和激活值进行量化
	- 如果只对权重进行量化,那么在计算激活值(FP32) × 权重(INT8)时,无法使用硬件的INT8加速计算单元,只能将INT8权重还原成FP32后,再使用FP32浮点乘法器去算
	- 激活值是变化的,但依旧不影响可以对激活值进行量化
		- 因为不同图片的激活值具备**数据分布相似性**和**校准**技术
			- 中心极限与分布收敛: 经过多层卷积加权求和后,某一层的激活值通常会收敛为类似于高斯分布或截断高斯分布
		- 虽然具体数值在变,但该层激活值的"总体取值区间"是高度稳定的
	- 对于偏置,通常不单独做INT8量化,而是直接量化为INT32,或保持FP32,因为偏置的数据量极小,对存储和计算开销影响微乎其微

### 种类

- 在真实工业界,全网经过四舍五入量化后,模型精度通常只会下降0.5%~1%左右,甚至几乎无损

#### 非对称量化

- 即可以映射到INT8,也可以映射到UINT8
- 最通用的方式: 将FP32的任意范围$[r_{min},r^{max}]$映射到INT8/UINT的整数范围$[q_{min},q_{max}]$
	- 对于无符号的UINT8: $[0,255]$
	- 对于有符号的INT8: $[-128,127]$

- 量化公式$$q = clamp(round(\frac{r}{S})+Z,q_{min},q_{max})$$
	- S(scale,缩放因子): 表示一个INT8单位步长代表多少FP32值
	- Z(Zero Point,零值偏移): 真实浮点数0.0量化后对应的整数值,且Z必须是整数
	- round(): 四舍五入的函数
	- $clamp(x,q_{min},q_{max})$: 截断函数,超出的部分直接阶段到最小值或最大值

	-  S: 两端长度比$$S = \frac{r_{max} - r_{min}}{q_{max} - q_{min}} \xrightarrow{} MinMax算法$$
	- Z: 
		- 将r = $r_{min}$,边界条件代入,对应的量化整数必须是$q_{min}$$$r_{min} = S × (q_{min} - Z) \xrightarrow{} Z_{float} = q_{min} - \frac{r_{min}}{S}$$
		- 必须对$Z_{float}$进行取整,并保证其不超出量化范围$$Z = clamp(round(q_{min}- \frac{r_{min}}{S}),q_{min},q_{mqx})$$
		
		- 如果计算出来的$Z_{float}$并不是刚好映射在整数节点
			- 强制将其"舍入"并"截断"为一个合法的整数,然后反过来微调(重新对齐)
			- **做法**:固定S不变,强行把Z改为整数,反过来微调浮点边界r(即拉伸\压缩覆盖的浮点表达范围)
				- 原始数据极边缘极其微小的一部分数据在阶段时会被Clamp掉
- 反量化公式$$\hat{r} = S × (q - Z)$$

#### 对称量化

- 即可以映射到INT8(绝大部分),也可以映射到UINT8(只需要保证Z = 0)
- 强制要求$r_{min}与r_{max}$对称,即零点偏移Z = 0

- 在进行矩阵乘法时,对称量化直接省去了交叉项的额外加法开销,硬件流水线更容易跑满

- **局限性
	- ReLU/GELU激活函数偏斜: 经过ReLU后的数据区间是$[0,100]$,负半轴全是0,会浪费很多的刻度

#### UINT8与INT8对比

- UINT8优势:
	- 空间利用率翻倍: 数值全为整数,若强制用有符号INT8,负数区间将完全浪费,数值精度分辨率会降低一半
- INT8优势:
	- 对称性好,天然支持有符号计算:神经网络权重通常以0为中心正态分布,使用INT8能完美贴合权重分布,且硬件乘法器对有符号整形计算支持更成熟

## KL散度

- 用于寻找最优的激活值截断阈值T,从而在截断异常极值与保留核心分布信息之间取得最佳平衡
- **前提假设**是"对称量化"

- 在将FP32浮点激活值映射到INT8时,量化的核心任务是确定缩放因子S:$$S = \frac{T}{127}$$
	- 绝对值小于T的数据会被映射到INT8的区间内
	- 绝对值大于T的数据会被截断为上限值
- KL散度量化法是根据基于概率分布相似度来自动寻找最佳阈值T的校准算法$$D_{KL}(P || Q) = \sum_{i = 1}^NP(i)\log(\frac{P(i)}{Q(i)})$$
	- $D_{KL}(P || Q) = 0$表示两个分布完全一致
	- $D_{KL}(P || Q)$越大,说明量化后的分布Q偏离原始分布P越远,模型表达能力的损失也就越大
- 如果阈值T选的太小,截断点之外的数据全部变成饱和最大值,造成截断误差
- 如果阈值T选的太大,包含无意义的离群值,会导致有效区间的量化误差大幅增加

- **目标**: 找到一个平衡点T,使得截断并量化后的分布Q与原始分布P的KL散度达到最小

- KL散度的局限性(使用对称量化)
	- ReLU/GELU激活函数偏斜: 如果强行用对称KL,映射区间会变成$[-100,100]$,使用ReLU/GELU会浪费掉INT8中整整一半的表达刻度
	- 双向非对称偏斜: 如果数据分布在$[-10,50]$正负半轴极不均衡,强行以0为中心找截断阈值T,会导致较小的一侧精度被严重稀释

### 非对称KL散度

- 打破单阈值限制,不再使用绝对值直方图,而是分别搜索正负方向的最佳截断阈值$[T_{min},T_{max}]$
- 默认是非对称量化
- 在搜寻$[T_{min},T_{max}]$时,使用二维格点搜索或分别对正负半轴计算KL散度最小化,彻底解决刻度浪费问题

## MSE(均方误差算法)

- 用于**校准/激活值**范围选择策略
- 通过**最小化量化前后张量之间的均方误差**,来自动寻找最贴合数据分布的最佳截断范围
- 允许截断一部分极端的离群点,将T调小,虽然离群点截断会引入饱和误差(截断误差),但换取了大多数正常数值精度的提升(降低了量化误差).MSE通过"饱和误差"和"量化误差"之间寻找平衡点,使总体重构误差最小

- **工作流程**
	- 收集校准数据: 传入小批量真实输入数据,向前传播,记录待量化层(权重或激活层)的FP32张量数据X
	- 确定搜索区间:
		- 找出张量的绝对值最大值$X_{max} = max(|X|)$
		- 设定搜索的最小阈值(直接0.5×$X_{max}$或通过分位数阈值)
		- 将该范围细分为N个候选阈值T1,T2.....
	- **网格搜索最佳T**
		- 对于每个候选阈值$T_i$
			- 基于$T_i$计算$$Scale = \frac{T_i}{127} \xrightarrow{} 用于确定刻度间距$$ 
			- 对原FP32张量X进行模拟量化和反量化,得到重构后的FP32张量$\hat{X}_i$$$\hat{X}_i = clip(round(\frac{X}{Scale_i}),-128,127)×Scale_i \xrightarrow{} 计算又T_i引起的量化的影响$$
			- 计算原张量与重构张量之间的MSE损失$$L(T_i) = \frac{1}{N}\sum{}{}(X-\hat{X})^2$$
