## YOLO RKNN端侧部署量化塌陷问题与解决方案复盘

- **初始异常**: 全量化模型在COCO验证集上推理时,mAP归零,即使更换为官方标准COCO val数据集后问题依旧

- 全INT8 -> 主干 + 检测头均INT8 -> mAP = 0(完全塌陷) -> 并非校准集质量问题,而是NPU对特定结构量化失控
- 混合A(敏感层/检测头设为FP16) -> mAP = 0(完全塌陷) -> 在NPU内部做局部层降级无效,交界处存在严重的量化畸变
- 混合B(主干设为PF16,检测头INT8) -> mAP = 0.4269(恢复正常) -> 证明主干层若用浮点,模型精度能保住(但NPU性能大打折扣)
- 切尾巴方案(主干INT8 + 尾巴放CPU FP32) -> mAP恢复正常
	- **最优解:** NPU跑INT8主干,CPU跑浮点尾巴,兼顾速度与精度
