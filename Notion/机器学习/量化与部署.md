# 量化与部署

> 模型量化、切片优化与部署格式。依赖神经网络概念，请先看 [[深度学习]]。
> 相关笔记：[[机器学习指引]] · [[经典机器学习]] · [[vision/C++ YOLO]] · [[日常学习总结/深度学习与边缘部署]]

## 1. 量化是什么

量化指将高精度的浮点数表示压缩为低精度的定点整数表示（如 FP32 → INT8）的过程，用于降低模型内存占用、实现硬件加速。量化带来的误差叫**量化误差**。
- 量化：连续 → 离散
- 反量化：离散 → 连续

## 2. 量化的分类

1. **权重量化** → 计算静态参数 → 使用 MSE 最优权重缩放（FP32 转 INT8）
2. **激活值量化** → 计算模型运行时产生的动态特征图 → 使用 KL 散度。推理时图像输入模型后各层产生的中间特征图是 FP32；nncase 要求提供校准集，就是为统计这些动态特征图数值范围、计算激活值的 Scale 和 Offset

## 3. MinMax 算法（激活值量化）

深度学习模型的权重和激活函数原本都是浮点数，而 INT8 只能表示 256 个整数。MinMax 的任务是找出一把标尺，把无数小数映射到这 256 个格子里：
1. **找边界**：找出一层中的最小值和最大值
2. **算步长**：计算数值长度范围，均匀切割成 256 份
3. **划分格子**：后续所有浮点数都除以步长并四舍五入

MinMax 缺点：数据中出现极大异常值时，中间绝大多数正常数据的精度损失严重。可改用 KL 散度算法（忽略两端极小概率离群值，专注保留中心核心数据）。

## 4. KL 散度（PTQ 熵校准）

允许截断极少数离群点，寻找最佳截断阈值 T，使截断前 FP32 概率分布 P 与量化/反量化后 INT8 概率分布 Q 之间的信息损失（KL 散度）最小。想法：把门槛设为一个数值，虽然一些激活值受影响，但整体完美。
1. 收集数据，算出详细直方图
2. 反复进行：① 滑动「截断门槛」，把极端数值移到门槛边缘 ② 将现有数值压缩再解压还原（截断后的 Bins 压缩到 INT8 的 128 个刻度，再扩展回未分割 Bins）③ 用 KL 散度打分，对比还原形状和原始形状差多少
3. 对比所有打分，找出信息损失最小的门槛

## 5. 权重量化采用 MSE

不直接使用最大值，而是寻找最优阶段阈值 α，使截断并量化后的权重与原浮点权重均方误差极小化。
- 提升精度的本质：牺牲极少数离群点的绝对精确度（轻微截断），换取中间高密度区域权重更细粒度的量化阶距

**权重用 MSE 而不用 KL**：
1. KL 散度算出的截断边界常不如直接 MSE 精确
2. 权重是训练好的静态参数，通常是零均值对称正态分布，用 MSE 去掉离群点后核心数据仍保持对称性和相对比例

**激活值用 KL 散度**：
- 防止被大量 0 绑架，保留最大信息量
- 用 MSE 会被海量 0 稀释全局误差，导致 MSE 不敢截断正数长尾，破坏正数特征分辨率
- KL 能除去 0，而 MSE 无法除去 0；激活值量化中存在大量 0

## 6. 量化的本质

量化是**线性仿射变换**，将实数区域映射到整数区域。
- **缩放因子 S**：正实数，代表整数区间中 1 刻度对应实数空间的物理跨度
- **零点 Z**：整数，代表真实实数 0 映射到离散空间的整数索引
  - 零点 Z 必须是精准整数。神经网络有大量 Padding（零填充）或 ReLU 输出的 0.0，若实数 0.0 映射成浮点数就无法用 INT8 整数数组精准表示，零填充会引入大量噪音、破坏特征提取能力

## 7. 量化的种类

**对称量化**：
- 固定 Z = 0（真实 0.0 必为 INT8 中的 0）
- 映射区间关于 0 轴对称
- 优势：硬件极其高效，矩阵乘法直接用纯整数乘加指令，无零点修正开销
- 缺点：遇到单边分布会浪费一半刻度，精度变差
- 应用于：权重（天然以 0 为中心）

**非对称量化**：
- Z ≠ 0，自由伸缩
- 优势：空间利用率高
- 缺点：运算时必须带 Z 实时偏置补偿，计算开销略大
- 应用于：激活值

## 8. 量化的处理类型

1. **Per-Tensor（按张量量化）**：整层矩阵共用一套 S 和 Z。省事但精度容易掉
2. **Per-Channel（按通道量化）**：每个卷积核/通道独立计算一套 S 和 Z。这是权重量化的标准做法（不同卷积核提取的特征数值量级差异大，分开量化大幅提升精度）

## 9. 量化处理方式

模型权重在两种量化中都在编译阶段提前量化好。唯一区别是对待激活值是「离线」量化还是「运行时」量化。
1. **静态量化**：提前用有代表性的校准数据集测量固定 S 和 Z，写进模型配置文件。不需现场统计，速度快到极致；若出现极端数据集可能有截断误差（数据超 INT8 范围被强行限制）
2. **动态量化**：对每张图片现场测量 S 和 Z，把数据转成 INT8。极其精准、无超范围问题、不需提前准备测试数据；但每层增加 CPU/GPU 额外开销

## 10. 校准

为让网络层寻找合理「取值边界」，关键部分得到更多刻度，保留数据细节：
- 找百来张图片，输入 FP32 模型跑前向传播，找每层网络输出的数据集中范围
- 计算缩放因子和零点
- 最终生成 INT8 量化模型

## 11. 混合精度

保持主干网络为 INT8 保证 KPU 硬件加速与推理帧率，将高敏感度的检测头或特殊层保留为 FP16 或 FP32。

**步骤**：
1. **敏感度分析**：编译时开启 nncase 的 Dump 和 analysis 功能，对比逐层 Tensor 在 FP32 与 INT8 下的余弦相似度，相似度低于 0.9 的层即为需锁定为 FP16/FP32 的敏感层
   - Dump：同时运行未量化的 FP32 模型和量化后的 INT8 模型，喂相同校准图片；每运行完一个算子，编译器拦截并把该层输出内存数据分别导出
   - Analysis：计算每层两个 Tensor 的统计指标（余弦相似度）。量化误差沿网络逐层累加，逐层对比能锁定敏感层
   - 余弦相似度：衡量两个向量在 N 维空间的方向一致性。1.0 方向完全一致；0.99 极微小失真，INT8 完整保留特征；<0.9 方向明显偏折，代表 INT8 量化破坏特征表达能力
2. **校准集核验**
3. **配置混合精度覆盖规则**：通过 nncase Python API 或配置文件，将敏感层设为 float
   - 检测头对 INT8 量化极敏感：
     1. 分类分支容错高（量化后概率下降但不影响判断）
     2. 回归分支对坐标极敏感：坐标框偏移几个像素，mAP@0.5:0.95 严重下滑
        - YOLOv8 检测头还用 DFL（回归积分），量化成 INT8 的 256 个离散网络后坐标产生严重截断误差。因为量化对 DFL 卷积层权重影响大：① 输出激活值精度问题导致末端微调信息丢失 ② 激活值与回归系数做点积时，概率微小误差被大系数放大，解码框可能抖动数个像素
4. **重新编译与 mAP/FPS 权衡评估**：生成的 kmodel 在目标板卡跑验证集，评估 mAP@0.5:0.95 回升及帧率变化；若回退到 CPU 的层过多，逐步裁剪 FP16 层数以保持帧率

## 12. PTQ（量化后训练）

先正常训练出完美的 float32 模型，导出 ONNX，再用校准集硬生生切成 INT8。
- 优点：不需重新训练，速度快，几分钟搞定
- 缺点：遇到对量化敏感的网络，精度易暴跌

## 13. QAT（量化感知训练）

在 PyTorch 训练阶段就把量化误差考虑进去。
- 优点：天生具备抗量化噪声的能力

**细节**：在前向传播中加入前向伪量化，反向传播用 STE（直通估计器）传递梯度，模型权重能在训练中自主适应量化噪声。伪量化即在前向传播中插入「模拟截断」模块：把浮点数量化成 INT8 再立即反量化回 FP32。以这种「假量化」方式，数据类型仍是 FP32，但数值已变成只有 256 个阶梯的离散值。

## 14. 为什么 sin、mul 这类算子在 uint8 下易失效，而卷积+激活能保持高 cos 相似度

1. **微小误差放大效应**：
   - 卷积层：通常用 ReLU/SiLU 激活，数据分布平滑、具线性特征，uint8 下微小量化截断误差只会让输出顺梯度轻微偏移，对特征图影响小
   - 角度/三角函数：非线性、周期性极强、变化剧烈，对输入极敏感，微小量化偏差被非线性变化剧烈放大
2. **范围与精度矛盾**：
   - 卷积层：ReLU 激活后数据全 >=0，映射 [0,255] 时 256 个阶梯全表示正数，分辨率高
   - 角度/三角函数：角度计算、坐标偏移含大量有正有负、集中在 0 附近的极小小数，用无符号 uint8 量化时负数部分需靠巨大 S、Z 硬凑，变换剧烈部分精度崩塌

## 15. 为什么量化能大幅提升硬件运行帧率并降低延迟

除了减少浮点计算开销外，从内存/带宽角度看，本质是**突破「内存墙」与提升缓存命中率**：
1. **节省内存带宽**：搬运同样数量的参数/特征，数据量衰减为 FP32 的 0.25，搬运时间大幅缩减（总线从 DRAM 搬运到 NPU/GPU 片上缓存 SRAM/Cache，再送 MAC 计算单元）
2. **提升 SRAM/Cache 命中率**：边缘侧片上缓存非常小；量化为 INT8 后 SRAM 一次能吞下更多权重和层间特征图，很多中间结果不需频繁「写回 DRAM → 读出 DRAM」，大幅降低端到端延迟
3. **提升寄存器与向量指令集并行度**：CPU/GPU/NPU 内部寄存器位宽固定，一次能存 4 个 FP32，能存 16 个 INT8；单条 SIMD 指令在同一周期内并行处理的数据量翻 4 倍

## 16. YOLO 网格 Logits

YOLO 网格在没有遇到极明显特征（或评估背景区域）时，输出的 Logits 会在 0 附近波动。如果直接看原始未激活数值 0.006，会觉得小得像 0；但 Logits 世界里 0 刚好是正负区分的「分界中点」。必须进行 Sigmoid 变换，并用 >0.5 的置信度阈值过滤，才能准确筛出真实目标。

## 17. 张量

张量本质上是一个「由数字堆叠起来的数据魔方」。就是把一张包含颜色和形状的图片，打碎重新排列成芯片喜欢的、有固定排布规则的数字立方体。

## 18. .pt 和 .onnx 文件的区别

**`.pt`**：包含项目源码和工程文件的「设计源文件/项目工程包」。
- 训练与研发阶段
- 强行绑定 PyTorch 和 Python
- 硬件无法直接识别或执行
- 模型容易修改

**`.onnx`**：脱离特定开发环境的「跨平台编译中间件」。
- 部署与落地阶段
- 与框架、语言无关
- 是 TensorRT、OpenVINO、nncase 等编译器的标准输入
- 仅用于前向推理，通常不可再逆向微调权重

## 19. 切片技术

切片是深度学习编译器及高性能图像中最核心的内存与算子调度优化手段。

### 做切片的原因
1. 大图像/大张量：尺寸大，必须保存在容量大但读取慢的板载运行内存
2. 片上高速缓存（SRAM）：紧挨 NPU/KPU 计算核心，速度快如闪电但容量非常小

### 原则
化整为零，分而治之：
1. 按空间（H/W）或通道（C）维度切成小块
2. 一块一块拉入片上超高速 SRAM
3. NPU 算完一块写回 DRAM，再装下一块

### 重叠区域
卷积核有感受野。切片时，邻近 Tile 必须重叠 1~2 个像素，确保边缘卷积时上下文不丢失、不产生裂缝断层。

### 双缓冲与流水线
为不让 NPU 在切换 Tile 时闲着，SRAM 分成 Ping 块和 Pong 块：NPU 对 Ping 计算时，DMA 同时在后台把下一个 Tile 装入 Pong；计算与搬运完全重叠。

### 感受野
感受野：神经网络中某一层的某个神经元能「看到」原始输入图像多大区域。
- CNN 中离输入越近的前几层感受野越小（只能看边缘、纹理细节）；离输出越近的深层感受野越大（看整体轮廓和上下文）
- **为什么切片重叠必须看感受野**：如果切片不做重叠区域，重叠边缘的卷积核因看不到「感受野之外的真实像素」，算出的数据是错的。重叠像素数至少要等于感受野半径

**小目标检测的坑**：
- 网络太深、下采样次数多时，深层感受野可能高达 200×200
  - 下采样：把大图变小图，用来「压缩信息、放大视野」。实现手段：① 池化（如 2×2 最大池化只保留最大像素，宽高减半）② 跨步卷积（卷积核跳着走隔一个像素采样，宽高减半）
- 若要检测的焊点只有 5×5，在巨大感受野下小焊点信息会被周围巨大环境稀释，导致漏检。所以 YOLO 等网络必须加 FPN（特征金字塔）把浅层小感受野特征保留下来
