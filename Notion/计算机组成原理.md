# 计算机组成原理

## 计算机的基本组成

- 软件: 由具有各类特征功能的信息组成
	- 系统软件 -> 为管理整个计算机系统所编制的程序
	- 应用软件 -> 为实现用户应用所编制的各种程序
- 硬件: 计算机的实体
	- 主机
	- 外设

- **冯诺依曼计算机的特点
	- 计算机由五大部件组成
		- 运算器: 负责进行算术运算和逻辑运算
		- 控制器: 负责从存储器中读取指令,对指令进行译码,并向各部件发出控制信号以协调工作
		- 存储器: 存放数据和程序
		- 输入设备: 将信息转换成机器能识别的形式
		- 输出设备: 将结果转换成人熟悉的形式
	- 指令和数据以同等地位位于存储器,可按地址寻访
	- 指令和数据用二进制表示
	- 指令由操作码和地址码组成
	- **存储程序** -> 具有存储结构的机器称为计算机
	- 以**运算器**为核心

### 系统复杂性管理方法

- **层次化与抽象
	- 分层设计: 将负责的计算机系统自底向上划分为不同的抽象层
		- 每一层都对上层隐藏内部实现的物理细节,仅通过明确定义的接口对外提供服务

- **模块化与结构化
	- 将功能紧密相关的逻辑组合在一起,模块之间通过标准的总线或数据通路通信
	- 标准部件标准化,避免重复设计

- **规范化与标准化
	- 使用结构高度规整的硬件阵列来替代零散的组合逻辑
	- 在RISC架构设计中,尽量采用固定长度的指令格式和统一的译码规则,简化译码器电路中的设计复杂性

- **局部性原理与层次化存储
	- **时间局部性与空间局部性**: 意识到程序访问数据和指令具有极强的时间与空间集中性
	- **层次化构建**: 构建"寄存器 -> L1/L2/L3 Cache -> 主存 -> 外存"的存储金字塔
	- **透明性管理**: 通过硬件机制或操作系统自动管理数据的流动,化解速度与容量的矛盾
