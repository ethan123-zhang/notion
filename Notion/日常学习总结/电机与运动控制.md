## 1. 矩与频

- **矩（力矩/扭矩）**：决定电机能带动负荷的负载。
- **频（脉冲频率/速度）**：步进电机靠输入脉冲信号驱动，脉冲频率越高旋转越快。

在**连续运行区域**：
- 低速时：电机能输出接近额定值的最大力矩（静力矩）。
- 高速时：力矩剧烈下降，负载超过当前频率的最大力矩就会**丢步**，甚至停转。

在**自启动区域**：
- 想达到更高速度不能直接给高频脉冲，必须先从低频启动，再通过程序控制加减速。

## 2. 丢步

丢步 = 控制系统发了指令，但电机没执行到位。原因：
1. 负载超过电机承载能力 → 合理选型。
2. 速度太快，力矩严重下滑。
3. 没有做加减速控制（直接加高频脉冲或紧急停止，没给电机留克服惯性的时间）→ 软件优化。
4. 电压或电流不够（驱动器供电电压太小、驱动芯片限流过小），电机无法发挥应有力矩 → 改善硬件供电。

最根本的解决方式：**增加编码器**（或改用闭环步进/伺服电机）。编码器实时把电机转过的实际角度反馈给驱动器，发现指令和实际对不上会自动补偿脉冲追回来；卡死追不回则立刻向主控报错停机。

## 3. 步进电机与伺服电机对比

| 项目 | 步进电机 | 伺服电机 |
|---|---|---|
| 输出转速 | 600 r/min | 3000 r/min |
| 矩频特性 | 转速越快扭矩越小 | 额定转速内恒力矩，超过则恒功率 |
| 过载能力 | 不具备，过载丢步 | 最大扭矩为额定 3 倍 |
| 定位精度 | 电机相数、驱动器细分设置 | 编码器分辨率（精度高） |
| 加速时间 | 0.2s | 0.1s |
| 控制方式 | 开环控制 | 半闭环控制 |

### 电机与舵机
- **舵机** = 直流电机 + 减速齿轮箱 + 位置传感器 + 控制传感器 + 控制电路。
- **电机**：通电就一直转，不通电就停。
- **舵机**：给定一个信号（如 PWM 波），内部电路板通过电位器测量当前角度，自动控制内部电机转到指定角度然后死死刹住。

### 驱控一体步进电机 vs 步进电机
- **步进电机**：上位机必须实时、不间断发送脉冲；电机离控制器远时，高频脉冲在长线缆中易受电磁干扰导致丢步。
- **驱控一体步进电机**：上位机只需丢一条简单文本/数据指令，高频驱动工作全部在电机内部闭环完成，抗干扰能力极强。
  - 驱控一体 = 控制器 + 驱动器 + 步进电机；可开环可闭环，装编码器即成闭环。

### 伺服电机
- **伺服电机** = 电机 + 尾部高精度编码器 + 伺服驱动器。
- 伺服驱动器相较于普通驱动器，自带 FOC（磁场定向控制）和 PID 闭环算法。

## 4. 电机选型

核心参数：
1. **堵转扭矩**：电机转不动时能输出的最大力矩。选型时绝不能用堵转扭矩作为工作扭矩，实际工作扭矩最好控制在堵转扭矩的 1/3~1/2 以内，否则电机极易过热烧毁。
2. **工作电压**：常见 7.4V、11.1V、12V、24V。移动小车优先选能与电池电压匹配的规格。
3. **控制精度/分辨率**：编码器分辨率越高，机械臂末端定位越准、运动越丝滑。
4. **42 步进 vs 35 步进**：
   - 保持扭矩：42 步进 0.2~0.6 Nm，35 步进 0.1~0.3 Nm（42 力气大得多）。
   - 重量：42 步进 200~450g，35 步进 130~250g。机械臂末端每重 10g，底座电机就要多付几倍力矩，35 能大幅减轻末端死重。
   - 输出轴径：两者均 5mm（决定同步轮或行星减速器内径）。
   - 转动惯量：42 较大、35 较小。35 转子惯量小，轻负载下启动和急停响应比 42 更灵敏。
5. **机身长度**：越长内部绕组越多、扭矩越大，但越重。
6. **额定电流与相电流**：若限制电压，电机在低压状态可能出现反电动势；电机内阻大电流难灌入，一转快就疯狂掉力甚至堵转。可选额定电流大（约 1.5~2.0A）、相电阻小（<2Ω）的电机。
7. **步进角**：
   - 1.8°（每圈 200 步）：高速性能好，价格便宜。
   - 0.9°（每圈 400 步）：运行更平稳、震动小，高速力矩较差。由于加行星减速器会放大角度分辨率，1.8° 已能达到极微小末端控制精度。
8. **双出轴与单出轴**：
   - 单出轴：电机只有前端一根轴，接减速器。
   - 双出轴：前后都有轴。前端接减速器，后端露短轴装闭环编码器磁铁。买闭环（带编码器）时即为双出轴。

> 电机控制本质：电压决定最高转速，电流决定最大扭矩。

## 5. PID 与 PD

- **P（比例）**：看现在。根据当前偏差大小输出控制量，偏差越大拉回力度越大。
- **I（积分）**：看过去。累积历史偏差，只要还存在微小静差，I 就不断累积，最终输出足够力把系统推到目标位置。
- **D（微分）**：看未来。根据偏差变化率输出，能感知系统变化趋势，相当于阻尼器。

区别：
- PID 存在微小静差，PD 能完全消除静差。
- PD 响应速度极快，PID 响应相对较慢。
- PD 能剧烈抵抗外部干扰，且对微小稳态误差不敏感。
- PID 要求最终 100% 精准到达、不能有误差，且系统状态相对变化没那么剧烈。

## 6. 步进电机驱动的算法思路：梯形/三角形速度曲线

1. 设定一个最终目标上限速度。
2. 根据当前时间走到哪一步（加速区、匀速区、减速区）计算一个百分比——每 50ms 检测一次。
3. 用上限速度乘以这个百分比得出当前实际速度，发送给小车。

加减速最快安全极限通常在 150~300ms，再快会发生：
1. 轮胎打滑（麦轮辊子构造在瞬间变速度时比橡胶轮胎更容易打滑；加速过快轮胎空转，磨损车轮，还导致编码器/里程计定位跑偏）。
2. 电机扭矩与电流堵转。
3. 车体翻车或晃动。

工程经验：
- 高效的比赛、车体轻量化、地面摩擦极好：200~400ms。
- 日常调试、视觉识别同时进行、搭载轻型设备：500~800ms。
- 运送易碎/易倒载荷、车体很重：1000~1500ms。

## 7. CoreXY 结构

- 纯 X 轴移动：两个电机同向旋转。
- 纯 Y 轴移动：两个电机反向旋转。

## 8. 电池电量对元器件的影响

- **对电机**：速度变慢、动力不足。即使 PWM 占空比一直 100%，绝对速度也随电量下降变慢；扭矩减少。
- **对舵机**：响应速度与保持力矩骤降，机械臂抓取软绵无力、反应迟缓；控制死区变大、定位不准。
- **红外/灰度循迹传感器**：红外发射二极管光强减弱。
- **无线通信模块**：导致通信频繁丢包或断联。

解决电压降低的方法：
- **硬件层面**：在电池与驱动器之间加一个大功率、高效率的自动升降压拓扑模块，无论电池电压在 10V~16V 之间如何波动，都稳定输出 12V 给电机、6V 给舵机。
- **软件层面**：动态 PWM 补偿，随电池电压下降自动慢慢开大占空比补偿功率损失，保证车速基本恒定。
- **运动控制层面**：引入闭环 PID，用带编码器的电机做速度 PID 闭环控制。

### 航模电池 vs 普通电池
- **普通电池（低倍率）**：容量 3000mAh，只允许几百毫安慢慢使用。
- **航模电池（高倍率）**：追求「瞬间爆发」。若 2000mAh 标注 50C，能爆发出 2Ah × 50 = 100A 电流。C 数越高，内部电阻越趋近 0。

## 9. 导电滑环

机械臂使用导电滑环后可顺时针/逆时针旋转无数圈，内部导线和信号绝不纠缠，电流和信号始终保持畅通。

## 10. 工创赛：底盘与自由度

**底盘**：
1. 两轮差速底盘。
2. 全向移动底盘（全向轮、麦克纳姆轮）——会有力浪费。
3. 四轮差速底盘。
4. 舵轮全向底盘。

前进时，电机转动速度不同（需做成闭环）、电池电量变化会导致误差。

**物体自由度**：描述物体状态所需的独立坐标轴。
- 机械臂的自由度：整个机构内部关节的数量，代表系统能独立运动的维度。
- 末端的自由度：机械臂各关节运动耦合后，在外部三维空间中表现出的运动能力（上限为 6）。
