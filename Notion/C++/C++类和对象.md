# C++ 类和对象

> 核心主题：内存分区、引用、构造函数、继承、多态、文件操作

## 1. 内存四大分区

C++ 执行时，将内存大方向划分为 4 个区域：

**运行前：**
- **代码区**：存放函数体的二进制代码，由操作系统管理
- **全局区**：
  - 全局变量（不在函数体内的变量）、全局数组
  - 静态变量（定义前加 `static`）
  - 常量：① 字符串常量 ② `const` 修饰的全局变量

**运行后：**
- **栈区**：编译器自动分配释放，存放形参、`const` 局部常量、局部变量、局部数组。函数结束后自动释放（**不要返回局部变量的地址**，结束后该内存已无效）
- **堆区**：由程序员分配和释放，若不释放，程序结束时由操作系统回收。用 `new` 关键字开辟

### 形参 / 实参
- **形参**：传递给被调函数的值
- **实参**：联系主调函数与被调函数，接受数值

### 字符串常量 vs 字符串变量
- **字符串常量**：只有双引号直接包裹的字面量（如 `"hello"`），一直存在
- **字符串变量**：`string` 字符串变量、`char` 字符串变量[]，可读可改；前面加 `const` 为只读

### new / delete
```cpp
int *p = new int(10);    // new 数据类型(数值)，返回该类型指针
delete p;                // 释放堆内存；delete != 指针悬空，只是释放内存
p = NULL;                // 释放后必须手动置 NULL，避免悬空指针

int *arr = new int[10];  // 数组
delete [] arr;
```
- 字符串不必用 `new`（字符串常量一直存在）
- 若不手动清除，程序结束后操作系统会清除；但**长期不释放且不结束运行**就会造成内存泄漏，该块内存一直处于占用状态无法利用

## 2. 引用

给变量起别名：`数据类型 &别名 = 原名`，原名与别名指向同一块内存。若用赋值（`int b = a`）则是拷贝、另开辟一块内存。

**注意：**
- 必须初始化（`int &b = a`，不能只写 `int &b`）
- 引用一旦初始化后不可更改
- 不要返回局部变量的引用（局部变量所在内存会随函数结束释放）

**功能：**
1. 形参为引用时，函数内的修改会改变外部原实参
2. 返回引用可视作 `接受变量 = 被返回变量/值` 的简化；返回类型是 `int` 返回拷贝值，`int &` 返回变量别名
3. 返回值是引用时可作为**左值**
4. 定义时加 `const`（`const 数据类型 &变量名`）后值和指向均不可改，常用于防止形参被修改；若一定要改，须用未限定 `const` 的变量

## 3. 默认参数 / 占位参数 / 函数重载

### 默认参数
有默认参数时，传入则用自己的数据，否则用默认值。
- 某位置有默认参数，其后所有位置都必须有默认参数
- 函数声明和实现只能有一个有默认参数（防止默认值不一致）

### 占位参数
语法：`返回值类型 函数名(数据类型)`，只占位不使用。

### 函数重载
函数名相同、提高复用性。条件：
1. 同一作用域（如都在全局作用域）
2. 函数名相同
3. 参数类型不同 / 个数不同 / 顺序不同（**返回值不可作为重载条件**）

注意：
- 重载碰到默认参数会产生二义性，会报错
- 重载遇到引用：参数一个是 `const int &a`、一个是 `int &a` 时，传入变量优先调用可读可写的 `int &a`；传入数值则调用 `const` 版本

## 4. 类与对象基础

- **类**：变量和函数的集合，语法 `class 类名 { public: 成员 };`
- **对象**：类实例化的结果，语法 `类名 类变量;`
- 类中的属性和方法统称**成员**；属性=成员属性/成员变量，行为=成员函数/成员方法（能直接利用对象的属性，普通函数不能）

### 访问权限（访问 = 合法接触到类内成员）

| 权限 | 类内 | 类外 | 继承关系 |
|---|---|---|---|
| `public` | ✅ | ✅ | — |
| `protected` | ✅ | ❌ | 子类（儿子）可以访问 |
| `private` | ✅ | ❌ | 子类（儿子）不可以访问 |

即使利用指针也无法访问 protected 和 private 成员。

### struct 与 class
唯一区别是默认访问权限：`struct` 默认公有，`class` 默认私有。

### 成员属性设置私有的好处
将属性一次性全设为私有，通过函数进行读写操作：
1. 可自己控制读写权限
2. 写操作可检测数据有效性（对写入值做限制）

### 头文件 / 源文件拆分
- **头文件**：引必要的头文件（在 `#define ...` 之后），并对类及其成员进行声明
- **源文件**：引一系列头文件，并对类的成员函数进行定义

### 值传递 vs 引用/指针传递
函数值传递会拷贝新数据；引用传递和指针传递不拷贝新数据。

## 5. 构造函数与析构函数

### 构造函数
作用：① 创建对象时 ② 为成员属性赋值，编译器自动调用一次，无需手动调用。
语法：`类名(){}`
- 无返回值也不写 `void`
- 函数名与类名相同
- 可以有参数，可发生重载

### 析构函数
作用：对象销毁前系统自动调用一次，释放堆区内存。
语法：`~类名(){}`
- 无返回值也不写 `void`
- 函数名与类名相同，名前加 `~`
- 不可以有参数，不可以重载

两者都放在类的 `public` 下；若不自己创建，系统会自动创建空实现版本。

### 构造函数的分类及调用
- 按参数分：有参构造（默认构造）和无参构造
- 按类型分：普通构造和拷贝构造（参数为 `const Person &p`，不可改 p 内容）

调用方式：
1. **括号法**：`Person p1(10)`
2. **显示法**：`Person p1 = Person(10);` `Person(10)` 是匿名对象（当前行执行结束自动销毁），赋值给 p1 相当于给它起名
3. **隐式转换法**：`Person p1 = 10`

当类同时有有参和无参构造时：创建对象不带参数 → 只能调无参；带参数 → 只能调有参。

### 拷贝构造函数
只能用同类型对象创建新对象；不要用拷贝构造初始化匿名对象（编译器会当作对象声明：`Person(p1)` 等同 `Person p1`）。

三种调用情况：
1. 用已创建好的对象初始化一个新对象
2. 值传递（一个类的对象），本质是重新拷贝
3. 值返回（一个类的对象），可能不拷贝（RVO 优化，不建议使用）

### 默认提供的三个函数
默认情况下 C++ 会给类添加：
1. 默认构造函数（无参、空函数体）
2. 默认析构函数（无参、空函数体）
3. 默认拷贝构造函数（对属性进行值拷贝）

调用规则：
1. 用户定义有参构造 → C++ 不再提供无参构造，但仍提供默认拷贝构造
2. 用户定义拷贝构造 → C++ 不再提供其他构造函数

### 浅拷贝 vs 深拷贝
- **浅拷贝**：简单的赋值拷贝操作
- **深拷贝**：在堆区重新申请空间进行拷贝

有堆区属性时必须自己提供深拷贝的拷贝构造函数，防止浅拷贝问题（相同内存空间不能连续释放，会出问题）。

### 初始化列表
```cpp
构造函数() : 属性1(值1), 属性2(值2), ... {}
构造函数(int a, int b, ...) : 属性1(a), 属性2(b), ... {}
```

### 类对象作为类成员
- 先创建类的对象，再对对象中的属性赋值
- 优势：一个类中可以调用另一个类的属性和功能
- 构造顺序：先构造其他类对象，再构造自身（析构顺序与构造相反）
- 可在外部函数传参时对内部函数属性赋值

## 6. 静态成员

成员变量/函数前加 `static`。

### 静态成员变量
- 不属于某个对象，所有对象共享同一份数据
- 在编译阶段分配内存
- **类内声明，类外初始化**：`数据类型 类名::静态成员变量 = 值;`（如 `int Student::age = 10;`）
- 私有作用域也可创建，但不可访问

### 静态成员函数
- 所有对象共享同一个函数
- 只能访问静态成员变量（无法区分是哪个对象的非静态属性）；非静态成员函数则两者都可访问
- 私有作用域也可创建，但不可访问

### 访问方式
1. 通过对象访问
2. 通过类名访问：`类名::静态成员变量`（`Person::age`）、`类名::静态成员函数`（`Person::func()`）

只有非静态成员变量属于类对象上。

## 7. this 指针 / 对象内存

- C++ 给每个**空对象**也分配 1 个字节，用于区分空对象占内存的位置
- 含非静态成员变量的对象，占用空间 = 非静态成员变量内存之和（不含静态成员属性和成员函数，它们不属于对象上）
- `this` 是隐含在每个非静态成员函数内的指针，无需定义。多个同类对象共用一份代码，`this` 指向被调用成员函数所属的对象

用途：
1. 形参与成员变量同名时用 `this` 区分：`this->age = age`（this 指向对象属性）
2. 在非静态成员函数中返回对象本身：`return *this`（用于链式编程）

**空指针调用成员函数**是允许的，但要注意是否用到 `this`（每次访问对象属性都隐藏地用到 `this`）。

### 常函数 / 常对象
- **常函数**：成员函数后加 `const`（如 `void showPerson() const {}`），修饰 this 指向，使指针指向的值不可被修改；常函数内不可修改成员属性
- **常对象**：声明对象前加 `const`；只能调用常函数（普通成员函数能改属性值）
- 成员属性声明时加 `mutable` 后，在常函数和常对象中依旧可修改

## 8. 友元

让一个函数或类访问另一个类的私有成员。在需要访问的类的上方进行说明，最前面加 `friend`。

1. **全局函数做友元**：`friend void Goodgay();`
2. **类做友元**：`friend class Goodgay;`
3. **成员函数做友元**：`friend void Person::visit();`

- 程序头部只能对类声明，无法对类的成员声明
- 解决「一个类调用另一个类且前向声明、定义不完全」的方案：只在类中声明函数，函数体写在被依赖类的完整定义之后

## 9. 运算符重载

对已有运算符重新定义，赋予其另一种功能，以适应不同数据类型。运算符重载也可以发生函数重载。

1. **加号运算符重载**：函数名固定 `operator+`，成员函数或全局函数二选一。内置数据类型（整型、浮点型）不可重载；不要滥用（如把相加定义成相减）；函数内部创建的对象返回**值**而非引用

2. **左移运算符重载**：为保证输出时 `cout` 在左边，只能通过全局函数重载

3. **递增运算符重载**：函数参数是否含 `int`（占位）区分前置/后置；前置返回引用，后置返回**值**（先赋值给临时对象再自增，返回临时对象）

4. **赋值运算符重载**：避免编译器清空同一块内存而报错，需开辟新的内存空间

5. **关系运算符重载**：对 `>`、`<`、`==`、`!=`、`>=`、`<=` 重载

6. **函数调用运算符重载**：对 `()` 重载，使用方式像函数调用，称**仿函数**；写法灵活，实际是在对象后加括号实现重载功能

### 匿名对象
- 语法：`类名()`
- 当前行结束立刻被释放

## 10. 继承

好处：减少重复代码。
语法：`class 子类 : 继承方式 父类`
- 子类 = 派生类，父类 = 基类
- 派生类成员 = 从基类继承的部分 + 自己新增的部分（继承体现共性，新增体现个性）

### 继承方式
父类中**私有权限**的内容子类一律访问不到（编译器隐藏了，但被继承下去了）。

| 继承方式 | 父类 public → 子类 | 父类 protected → 子类 |
|---|---|---|
| 公共继承 | public | protected |
| 保护继承 | protected | protected |
| 私有继承 | private | private |

父类所有非静态成员属性都会被继承下去（含私有权限的属性）。

构造顺序：先调父类构造，再调子类构造；析构顺序与构造相反。

### 同名成员处理
1. 子类出现与父类同名成员属性（无视类型和作用域），子类隐藏父类值
2. 子类出现同名成员函数，会隐藏父类**所有**同名函数（含重载）
3. 访问被隐藏的父类成员需加作用域：`s.Base::func()`
4. 同名静态成员处理与非静态相同，只是多一种访问方式（通过对象和类名）

### 多继承
语法：`class 子类 : 继承方式 父类1, 继承方式 父类2 ... {};`
多个父类有同名成员时需要加作用域区分。

### 菱形继承
```
A → B → D
  → C
```
- 两个父类（B、C）有相同数据，即使相等也不能直接通过子类 D 访问，需加作用域
- 数据会存在两份，造成资源浪费
- 解决：在 B、C 继承 A 前加 `virtual` 变成**虚继承**，A 即虚基类；B、C 若未初始化变量，虚继承使它们得到相同数据

## 11. 多态

多态：同一种行为作用在不同对象上产生不同结果——接口统一、实现各异。

好处：代码结构清晰、可读性强、利于前后期扩展和维护。

### 静态多态
函数重载和运算符重载。函数地址**早绑定**（编译阶段确定地址）。

### 动态多态
派生类和虚函数实现运行时多态。函数地址**晚绑定**（运行阶段确定地址）。

满足条件：
1. 有继承关系
2. 子类重写父类虚函数（重写 = 返回值类型、函数名、参数列表完全相同）

逻辑：
- 父类函数前加 `virtual` 变成虚函数，该类（及所有子类）拥有**虚函数表**（每类一份），表内存父类所有虚函数地址；子类重写后，表中原地址被新地址取代
- 每个对象实例自动创建**虚函数指针**指向虚函数表，调用哪个表的虚函数指针就指向哪个
- 虚函数表属于类，虚函数指针属于实例化对象

使用：父类指针或引用指向子类对象（父类和子类可直接类型转换，父类引用可直接指向子类）。

### 纯虚函数和抽象类
多态中父类虚函数实现通常无意义，主要调子类重写，可写成纯虚函数。
语法：`virtual 返回值类型 函数名(参数列表) = 0;`

含纯虚函数的类称为**抽象类**：
- 无法实例化对象
- 子类必须重写纯虚函数，否则也属抽象类、无法实例化

类 B 继承类 A 时继承了 A 的虚函数，要在类外重写时需在类 B 中声明该函数。

### 虚析构 / 纯虚析构
问题：父类指针指向子类对象时，父类指针析构不会调用子类析构函数，若子类有堆区属性会导致内存泄漏。

共性：
- 都能解决父类指针释放子类对象
- 都需要有具体函数实现

区别：
- 纯虚析构使该类成为抽象类，无法实例化对象
- 纯虚函数无需类外定义；纯虚析构函数必须在类外写函数体

使用情况（需同时满足）：① 在子类堆中创建变量 ② 使用父类指针指向子类变量

## 12. 文件操作

程序运行时产生的数据都是临时数据，程序结束后被释放；可通过文件将数据持久化。操作文件需包含 `<fstream>`。

文件类型：
- **文本文件**：以文本的 ASCII 码形式存储
- **二进制文件**：以二进制形式存储，用户一般不能直接读懂

三大操作类：
- `ofstream`：写文件
- `ifstream`：读文件
- `fstream`：读写文件

### 打开方式

| 方式 | 说明 |
|---|---|
| `ios::in` | 为读文件而打开 |
| `ios::out` | 为写文件而打开 |
| `ios::ate` | 初始位置为文件尾 |
| `ios::app` | 追加方式写（所有写操作强制在文件末尾执行，不能改读写指针位置） |
| `ios::trunc` | 文件存在先删除再创建（须与 `ios::out` 搭配） |
| `ios::binary` | 二进制方式 |

打开方式可用 `|` 配合使用。路径含中文可能无法写入。

### 写文件步骤
1. 包含头文件：`#include <fstream>`
2. 创建流对象：`ofstream ofs;`
3. 打开文件：`ofs.open("文件路径", 打开方式);`
4. 写数据：`ofs << "写入的数据";`
5. 关闭文件：`ofs.close();`

### 读文件步骤
1. 包含头文件：`#include <fstream>`
2. 创建流对象：`ifstream ifs;`
3. 打开文件并判断是否成功
4. 读数据
5. 关闭文件：`ifs.close();`

读取方式一（`>>`，按空白分隔）：
```cpp
char buf[1024] = {0};
while (ifs >> buf) {
    cout << buf << endl;
}
```
- `buf` 存的是「字节」而非「字符」，按控制台默认编码解析显示
- `ifs >> buf` 自动跳到开头空白字符；遇到空白字符结束本次读取，下次从开头覆盖写
- 前一次读取序列比后一次长且未覆盖完时，打印可能残留前一次内容；但每次写数据会在末尾写 `\0`，不影响读取
- 只读取 ≤1023 个字符

读取方式二（`getline`，按行）：
```cpp
char buf[1024] = {0};
while (ifs.getline(buf, sizeof(buf))) {
    cout << buf << endl;
}
```
- `getline` 按「行」读取，直到遇到换行符，一整行内容都会计入
- 写入后文件读写指针自动移到内容末尾，可能导致无法打印，需 `ifs.seekg(0);` 移回第 0 字节
- `getline` 完整读取整行所有字符（含手动加的空格）；空格和 `\0` 有本质区别，`cout` 可读空格
- `\0` 数值上等于 0，但专指「字符串结束符」，与普通数字 0 含义不同

读取方式三（string 版全局函数）：
```cpp
string buf;
while (getline(ifs, buf)) {
    cout << buf << endl;
}
```
- 此为全局函数 `getline`，之前的是类中的成员函数

- `EOF` 表示文件尾；`exit(0)` 强制结束程序（属 `<cstdlib>`）
- `#include <iostream>` 引入标准库实体（类、函数、对象）的声明/定义；`using namespace std;` 简化对这些实体名称的访问

### 二进制读写
借助类写文件：
```cpp
class Person {
public:
    char m_Name[64]; // 用 C 语言方式接收
    int m_Age;
};

ofstream ofs;
ofs.open("Person.txt", ios::out | ios::binary);
Person p = {"张三", 18}; // 全部成员在 public 且满足聚合类型条件时，可像结构体一样赋值
ofs.write((const char*)&p, sizeof(p));
ofs.close();
```

借助类读文件：
```cpp
class Person {
public:
    char m_Name[64];
    int m_Age;
};

ifstream ifs;
ifs.open("Person.txt", ios::in | ios::binary);
if (!ifs.is_open()) {
    cout << "文件打开失败" << endl;
}
Person p;
ifs.read((char*)&p, sizeof(p));
cout << "姓名：" << p.m_Name << endl;
```

通用二进制写：
```cpp
ofstream write_file("文件名.bin", ios::out | ios::binary);
```

## 13. 杂项

- `#pragma once`：防止文件重复包含
- 全局变量必须在头文件中「声明」（用 `extern`），且只能在一个 `.cpp` 文件中「定义」
- string 字节容器（UTF-8）：字母、数字占 1 字节，普通汉字占 2 字节
- `replace` 替换汉字：`replace(起始索引, 替换的字节数, 新内容)`
- `s.substr(1, 3);` 从第 1 个字符开始取 3 个字符
- `stoi()`：字符串转整型
- `char[]` 创建的字符串不能直接比较相等，要用 `strcmp(a, b)`
