# C++ STL（标准模板库）

STL（Standard Template Library，标准模板库）。

- 目的：建立统一标准的数据结构和算法。
- STL 广义上分为：**1. 容器，2. 算法，3. 迭代器**。
- 容器和算法之间通过迭代器进行无缝衔接。
- STL 几乎所有的代码都采用了模板类或者模板函数（提高了复用性）。

## STL 六大组件

1. **容器**：各种数据结构，如 vector、list、deque、set、map 等用来存放数据。将运用最广泛的一些数据结构实现出来。
   - **序列式容器**：强调值的排序，序列式容器中的每个元素均有固定的位置（简单来说：放入的位置顺序是不进行改变的）。
   - **关联式容器**：二叉树结构，各元素之间没有严格的物理上的顺序关系（简单来说：放入的时候就已经进行了排序）。
2. **算法**：各种常用的算法，如 sort、find、copy、for_each 等。算法（algorithm）：用有限的步骤，解决逻辑或数学上的问题。
   - **质变算法**：是指运算过程中会更改区间内的元素的内容，例如拷贝、替换、删除等。
   - **非质变算法**：是指运算过程中不会改变区间内元素的内容，例如查找、计数、遍历、寻找极值等。
3. **迭代器（复合数据类型）**：扮演容器和算法之间的胶合剂（当指针使用即可）。提供一种方法，使之能够依序寻访某个容器所需的各个元素，又无需暴露该容器的内部表示方式。每个容器都有自己专属的迭代器。
   - **双向迭代器**：能进行读写操作，并能向前和向后操作。
   - **随机访问迭代器**：能进行读写操作，可以以跳跃的方式访问任意数据，功能最强的迭代器。
4. **仿函数**（就是重载的小括号）：行为类似函数，可作为算法的某种策略。
5. **适配器**：一种用来修饰容器或者仿函数或迭代器接口的东西。
6. **空间配置器**：负责空间的配置与管理。

## 各容器对比

### vector 与普通数组的区别

- 数组为静态空间：设置一段内存之后就无法扩展。
- vector 为动态空间：设置好内存之后可以动态扩展。
- 动态扩展并不是在原空间之后续接新空间，而是找更大的内存空间，然后将原数据拷贝到新空间，释放原空间。

### deque 与 vector 的区别

1. vector 对于头部的插入删除效率低，数据量越大，效率越低。
2. deque 相对而言，对于头部的插入删除速度比 vector 快。
3. vector 访问元素的速度会比 deque 快，这和两者内部实现有关。

### 链表的优缺点

- 优点：可以对任意位置进行快速插入；采用动态存储分配，不会造成内存浪费和溢出。
- 缺点：容器遍历速度没有 vector 容器快；占用空间比数组大。
- 进行插入和删除操作时，原有的 list 迭代器不会失效，但 vector 可能会失效。

### set 和 multiset 的区别

set 不可以插入重复数据，而 multiset 可以。

## 容器详解

> 注意：容器在使用的时候要注意引入头文件。

### 1. vector

vector 属于尾部进、尾部出的容器。

- 迭代器：
  - `v` 是 `vector<int>` 类的实例对象，可以使用 `.` 访问对象的成员（成员变量和成员函数），但类的嵌套类型（比如 iterator）属于类本身，不属于类的某个对象，因此不能通过对象访问嵌套类型。
  - `vector<int>::iterator itBegin = v.begin();`：起始迭代器，指向容器中第一个元素。
  - `vector<int>::iterator itEnd = v.end();`：结束迭代器，指向容器中最后一个元素的下一个位置（指向的位置是空的）。
  - 注意 1：当容器重新分配内容时，可能会使之前保存的迭代器失效。
  - 注意 2：vector 容器创建的变量的名字不是指针，可以将迭代器当指针进行访问。
- vector 容器的迭代器是支持**随机访问**的迭代器。

**通过 vector 的构造函数创建新对象：**

- `vector<int>v`：利用无参构造的方式，创建 vector 容器。
- `vector<int>v2(v1.begin(),v2.end())`：利用有参构造的方式，传入两个迭代器，将 `[v1.begin(),v1.end())` 的部分传入。
- `vector<int>v3(n,m)`：向 v3 中传入的是 n 个 m。
- `vector<int>v4(v3)`：利用拷贝构造，将 v3 的值拷贝到 v4 中去。

**vector 赋值操作：**

- `v2 = v1`：使用 operator= 的方式进行赋值。
- `v3.assign(v1.begin(),v1.end())`：v3 取到的值是 v1 的 `[v1.begin(),v1.end())`。
- `v4.assign(n,m)`：给 v4 赋值的是 n 个 m。
- 注意：`assign()` 并没有传入 vector 对象赋值的操作。

**vector 容量和大小：**

- `v1.empty()`：如果 v1 为空，则返回 true；如果 v1 不为空，则返回 false。
- `v1.capacity()`：返回的是 v1 的容量值，本质上是最大可存储的元素个数（与字节无关）。
- `v1.size()`：返回的是 v1 目前存储元素的大小。
- `v1.resize(n,m)`：将 v1 的大小扩展至 n，未占用的部分用 m 来代替（m 默认为 0），新添的数据会占用在未占用的区域。如果重新指定的大小比原来短了（容量大小不会改变），那么超出的部分会被删除掉。

**vector 插入和删除：**

- `v1.push_back(ele)`：在尾部插入元素 ele。
- `v1.pop_back()`：删除最后一个元素。
- `v1.insert(pos,ele)`：在迭代器指向的位置之前的空位中插入 ele。
- `v1.insert(pos,count,ele)`：在迭代器指向的之前的空位中插入 count 个 ele。
- `v1.erase(pos)`：删除迭代器指向的元素。
- `v1.erase(v.begin(),v.end()) <==> clear()`：删除容器中所有元素。
- 注意：插入和删除元素全都是用的迭代器，并不是索引。

**vector 数据存取：**

- `v1.at(索引值)`：返回索引指向的数据。
- `v1[索引值]`：返回索引指向的数据。
- `v1.front()`：返回容器中第一个数据元素。
- `v.back()`：返回最后一个数据元素。

**vector 互换容器：**

- `v1.swap(vec)`：将 vec 与本身的元素互换（实质是容器的交换）。
- 用途——收缩内存：将容量大小减小为实际存储数据的大小，减少内存浪费（`vector<int>(v).swap(v)`：使用匿名对象拷贝 v，再和之前的容器进行互换）。

**vector 预留空间：**

- 目的：减少 vector 在动态扩展容量时的扩展次数。
- `reserve(n)`：容量预留 n 个元素长度，预留的位置不初始化，元素不可访问（只是分配了内存，并未初始化）。
- 总结：如果数据量较大，可以一开始利用 reserve 预留空间。

### 2. string

string 是一个类，内部封装了 `char*`，管理这个字符串，是一个 `char*` 型的容器。

> 注意：如果 "ABCDE" 中抽出来一个字母，这个字母是字符，而不是字符串（使用 `typeid(s).name()` 查看数据类型）。

**string 的构造函数：**

1. `string 新建的字符串名`：构造空字符串。
2. `string 新建的字符串名(字符串)`：使用字符串初始化，不能是单个字符。
3. `string 新建的字符串名(string对象)`：使用一个 string 对象初始化另一个 string 对象。
4. `string 新建的字符串名(字符个数,单个字符)`：可以用于将字符转化为字符串（注意：不能使用 `string s1 = s[i]` 转换，因为两边的类型不同）。

> string 有多种构造函数，它们之间没有可比性，灵活使用即可。

**字符串赋值操作：**

1. 字符串对象 = 所要赋值的字符串或字符。
2. 字符串对象 = 所要赋值的字符串对象。
3. 字符串对象.assign(字符串或字符串对象)。
4. 字符串对象.assign(字符串,数字n)：将字符串的前 n 个字符进行赋值。
5. 字符串对象.assign(字符个数,单个字符)。

> 一般使用 operator= 的方法进行赋值。

**字符串拼接：**

1. 字符串对象 += 字符串、字符、字符串对象。
2. 字符串对象.append(字符串、字符串对象)。
3. 字符串对象.append(字符串,数字n)：从字符串索引的第 n 个开始提出变量，再拼接。
4. 字符串对象.append(字符串,数字n,数字m)：将字符串中的第 n 个字母拼接 m 个字母。

**字符串查找：**

- 字符串对象.find(要找的字符、字符串、字符串对象, 查找的起始位置（如果不给出则默认为 0）)：如果找到目标字符或字符串，则返回该字符或字符串的第一个字符的索引；如果没找到则返回 -1。
- `rfind` 是从右往左找，`find` 是从左往右找。

**字符串替换：**

- 字符串对象.replace(n,m,所要替换的字符或字符串)：从索引 n 开始，m 个字符被替换。

**字符串比较：**

- 字符串对象.compare(字符串对象或字符串)：将两个字符串对象的字符根据 ASCII 值逐个进行比较，主要是比较两个字符串时候相等，相等返回 0。

**字符串长度的获取：**

- 字符串对象.size()：返回的是字符串的长度。

**string 字符存取：**

- 字符串对象[n]：返回索引值为 n 的字符。
- 字符串对象.at(n)：返回索引值为 n 的字符。
- 也可以进行赋值操作。

**string 插入和删除：**

- 字符串对象.insert(插入位置的索引,字符串或字符串对象)：在索引位置前面进行插入。
- 字符串对象.erase(插入位置的索引,n)：从起始位置开始，删除 n 个字符。

**string 的字串：**

- 字符串对象.substr(n,m)：从索引 n 开始，返回之后 m 个字符。

**将浮点型或整型转换成字符串：**

- `to_string(num)`

### 3. deque 容器

功能：双端数组，可以对头端和尾端进行插入删除操作。deque 容器的迭代器也是支持随机访问的。

**deque 的构造函数：**

1. `deque<int>d;`：默认构造函数。
2. `deque<int>d1(d.begin(),d.end())`：有参构造函数。
3. `deque<int>d1(n,m)`：有参构造，将 n 个元素 m 传入容器中。
4. `deque<int>d1(d)`：拷贝构造。

> 注意：如果在函数中规定了 deque 容器为只读（`void printDeque(const deque<int>v)`），那么应该使用只读迭代器（`deque<int>::const_iterator it`）。

**deque 赋值和交换：**

1. `d = d1`：使用 = 对 deque 容器进行赋值操作。
2. `d.assign(d1.begin(),d1.end())`：将 d1 中的元素赋值给 d。
3. `d.assign(n,ele)`：将 n 个 ele 元素赋值给 d。
4. `d.swap(d1)`：将 d 中和 d1 的元素进行互换。

**deque 大小操作：**

1. `d.empty()`：判断容器是否为空。如果为空返回 true；如果不为空返回 false。
2. `d.size()`：返回容器中元素的个数。
3. `d.resize(num,ele = 0)`：重新指定容器的长度，若变长则将未占用数据的部分用 ele 填充；若变短，则删除末尾超出容器的元素。

> 注意：deque 容器没有容量这一说。

**deque 插入和删除：**

两端插入操作：
- `push_back()`：在容器尾部添加一个数据。
- `push_front()`：在容器头部插入一个数据。
- `pop_back()`：删除容器最后一个数据。
- `pop_front()`：删除容器头部第一个数据。

指定位置操作：
- `insert(pos,ele)`：在 pos 位置插入一个 ele 元素的拷贝。
- `insert(pos,n,ele)`：在 pos 位置插入 n 个 ele 数据，无返回值。
- `insert(pos,beg,end)`：在 pos 位置插入 `[beg,end)`。
- `erase(beg,end)`：删除 `[beg,end)` 区间的数据。
- `erase(pos)`：删除 pos 位置的数据，返回下一个数据的位置。
- `clear() <==> erase(d.begin(),d.end())`：清空容器中所有数据。

> 注意：pos、beg、end 要求是迭代器。

**deque 数据存取：**

1. `d.at[索引值]`：返回索引指向的数据。
2. `d[索引值]`：返回索引指向的数据。
3. `d.front()`：返回容器中第一个数据。
4. `d.back()`：返回容器中最后一个数据。

### 4. stack 容器

stack 是一种先进后出的数据结构，并且只有一个出口（栈顶）。栈不允许有遍历行为（遍历不允许容器的数据发生改变）。

- **构造函数：**
  - `stack<int>stk`：默认构造形式。
  - `stack stk(stk1)`：拷贝构造。
- **赋值操作：** `stk1 = stk2`
- **数据存取：**
  - `stk.push(ele)`：向栈顶添加元素。
  - `stk.pop(ele)`：从栈顶移除元素。
  - `stk.top()`：返回栈顶元素。
- **大小操作：**
  - `stk.empty()`：判断栈是否为空。
  - `stk.size()`：返回栈的大小。

### 5. queue 容器（队列容器）

queue 是一种先进先出的数据结构，有两个出口。队列容器允许从一段新增元素，从另一端移除元素。队列中只有队头和队尾可以被外界使用，因此队列不允许有遍历行为。队列中进数据的行为被称为入队，出数据的行为被称为出队。

- **构造函数：**
  - `queue<int> que`：默认构造函数。
  - `queue<int> que(que1)`：拷贝构造。
- **赋值操作：** `que1 = que2`
- **数据存取：**
  - `que.push(ele)`：队尾添加元素。
  - `que.pop()`：删除队头的元素。
  - `que.back()`：返回队尾的元素。
  - `que.front()`：返回队头的元素。
- **大小操作：**
  - `que.empty()`：判断队列是否为空。
  - `que.size()`：返回队列的大小。

### 6. list 容器（链表）

链表是一种物理存储单元上非连续的存储结构，数据元素的逻辑顺序是通过链表中的指针链接实现的。功能：将数据进行链式存储。

- 链表的组成：链表由一系列结点组成。
- 结点的组成：一个是存储数据元素的数据域，一个是存储下一个节点地址的指针域。
- STL 的链表是一个**双向循环链表**（每一个结点的指针域记录了前一个节点的地址，又记录了后一个节点的位置（第一个和最后一个结点相互指向））。
- 链表属于双向迭代器，因为链表的存储方式并不是连续的内存空间，因此链表中的迭代器只支持前移和后移。

**构造函数：**

- `list<int> lst`：默认构造。
- `list<int> lst(beg,end)`：将 `[beg,end]` 区间中的元素拷贝给本身，beg 和 end 都是迭代器。
- `list<int> lst(n,ele)`：构造函数将 n 个 ele 拷贝给本身。
- `list<int> lst(lst1)`：拷贝构造。

**list 赋值和交换：**

- `lst.assign(beg,end)`：将 `[beg,end)` 区间中的数据拷贝赋值给本身。
- `lst.assign(n,ele)`：将 n 个 ele 赋值给 lst。
- `lst = lst1`：将 lst1 中的内容赋值给 lst。
- `lst.swap(lst1)`：将 lst1 和 lst 中的元素进行互换。

**list 大小操作：**

- `lst.size()`：返回容器中元素的个数。
- `lst.empty()`：判断容器是否为空。如果为空返回 true；如果不为空返回 false。
- `lst.resize(num,ele = 0)`：重新指定容器的长度，若变长则将未占用数据的部分用 ele 填充；若变短，则删除末尾超出容器的元素。

**list 插入和删除：**

- `lst.push_back(elem)`：在容器尾部加入一个元素。
- `lst.pop_back()`：删除容器中最后一个元素。
- `lst.push_front(ele)`：在容器开头插入一个元素。
- `lst.pop_front()`：移除容器开头第一个元素。
- `lst.insert(pos,ele)`：在 pos 索引位置前插入元素 ele。
- `lst.insert(pos,n,ele)`：在 pos 索引位置前插入 n 个 ele 元素。
- `lst.erase(pos)`：删除索引 pos 位置的元素。
- `lst.erase(beg,end)`：删除从迭代器 beg 到迭代器 end 前一个元素之间的所有元素。
- `lst.clear() == lst.erase(l.begin(),l.end())`：清空容器中所有元素。
- `lst.remove(ele)`：删除容器中所有值为 ele 的元素。

**list 数据存取：**

- `lst.front()`：返回第一个元素。
- `lst.back()`：返回最后一个元素。

**list 反转和排序：**

- `lst1.reverse()`：将 lst1 进行反转。
- `lst1.sort()`：将 lst1 进行排序，默认的排序规则是从小到大。
  - 若要变成降序：`lst1.sort(compare)`，其中 `bool compare(int v1,int v2){return v1>v2}`。
  - 如果是对自定义数据类型进行排序，可以通过 if 语句进行改规则：

```cpp
bool myCompare(Person &p1, Person &p2) {
    if (p1.age != p2.age) {
        return p1.age > p2.age;
    }
    if (p1.age == p2.age) {
        return p1.stature < p2.stature;
    }
}
```

### 7. set 容器

所有元素都会在插入时自动被排序。

**set 和 multiset：**

- 相同点：set/multiset 属于关联式容器，底层结构是用二叉树。
- 不同点：set 不允许容器中有重复元素；multiset 允许容器中有重复的元素。

**set 构造和赋值：**

- `set<int> st;`：普通构造。
- `set<int> st(st1);`：拷贝构造。
- `st = st1`：将 st1 赋值给 st。

**set 大小和交换：**

- `st.size()`：返回容器中元素的数目。
- `st.empty()`：判断容器是否为空。如果为空返回 true；如果不为空返回 false。
- `st.swap(st1)`：将 st1 和 st 中的元素进行互换。

**set 插入和删除：**

- `st.insert(ele)`：向容器中插入元素。
- `st.clear()`：清除容器中所有元素。
- `st.erase(pos)`：删除迭代器所指元素。
- `st.erase(beg,end)`：删除区间 `[beg,end)` 中的所有元素。
- `st.erase(ele)`：删除元素 ele。

**set 查找和统计：**

- `st.find(key)`：查找 key 是否存在，若存在返回该键的元素迭代器；若不存在，返回 `st.end()`。
- `st.count(key)`：查找 key 的元素个数。

### 8. pair

用处：将任意两个数据类型打包在一起，变成新的整体。

```cpp
pair<int,int> myBone = {5,7};
int a = myBone.first;
int b = myBone.second;
```

## 范围 for 循环

`for(const auto& bine:skeleton)` 相当于 `for bone in skeleton`：

- 将 skeleton 中的每个元素挨个拿出来，起个临时名字 bone。
- `auto`：表示自动推导数据类型。
- `&`：表示直接引用。
- `const`：表示只读。

## 算法

需要包含头文件 `algorithm`。

1. `for_each(v.begin(),v.end(),my_print)`：第一个位置放置起始迭代器或指针，第二个位置放置终止迭代器或指针，最后一个位置放置函数名（不需要括号）。for_each 会将迭代器或指针解引用放到传入的函数中。
2. `sort(beg,end)`：对 beg 和 end 区间内的元素进行排序。
   - 注意：beg、end 都是迭代器。
   - `sort()` 默认是升序算法。
   - 对于支持随机访问的迭代器的容器，都可以利用 sort 算法直接对其进行排序；不支持随机访问迭代器的容器，容器本身会提供对应的算法。

**内置 swap 情况：**

- list、set、vector、deque 都内置了 `swap()`。
- 而 queue 和 stack 只能通过算法 `swap(q1,q2)` 实现。

## 指针与取地址

- 数组名本身是指针，但是是只读状态，只能通过其他指针指向这个地址，做到可改。
- 取地址时：
  - 使用 `&` 是对一个普通变量取地址。
  - 使用 `*` 是对指针变量解引用，或告诉编译器变量是指针。
